## Global Constraints

- Один тяжёлый прогон за раз, `flock /tmp/ai-ecosystem-build.lock`. Playwright и нативные
  тесты — последовательно, не параллельно.
- SQL prepared only; деньги `UPDATE ... WHERE guard RETURNING`. Не трогать применённые миграции.
- Тесты без внешних вызовов и реальных денег; провайдеры — заглушки.
- Не деплоить, не пушить, не мержить. Коммит — контролёром одним проходом.
- Ничего не выдавать за приёмку без фактического прогона. Зелёный тест без артефакта
  прогона = UNVERIFIED, а не PASS.
- Соответствие claims проверять по коду, а не по документации.
