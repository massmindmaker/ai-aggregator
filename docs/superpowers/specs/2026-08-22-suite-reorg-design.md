## 2. Решения основателя

1. **Стратегия B:** монорепо остаётся кодовым каноном; деплой и разработка не переезжают. «Разделение» = структура папок + зеркала.
2. **Раскладка (вариант 2):** родительская папка `projects/aggregator`, монорепо внутри как `core/`.
3. **Зеркала (вариант A):** перезаписать `massmindmaker/agent-market` актуальным subtree TMA; создать новый `massmindmaker/ai-aggregator-web`; для конкурсов репо пока не создавать.
4. **Три проекта в ментальной модели:**
   - `ai-aggregator` — маркет + модели (web + gateway);
   - `agent-market` — маркет агентов: **TMA** + **web-app** (веб-версия пока живёт в коде `apps/web` как скрытый `/agentmarket`);
   - `ai-contest` — конкурсная площадка (код пока в `apps/web` routes + `apps/worker` sink).
5. **Чистота:** после реорганизации «ничего лишнего» — см. критерии приёмки §8.
