# Дизайн: TMA-редизайн, под-проект A — каркас + Маркет-персонажи + Дэшборд + Кошелёк + Аккаунт

**Дата:** 2026-06-12 · **Статус:** утверждён основателем (дизайн), ждёт ревью спека
**Контекст:** форензик-ревью показал «два разных приложения» — построенный биржевой хаб разошёлся с каноничным дизайнбордом (лента карточек-персонажей = сигнатура PRODUCT.md). Этот под-проект возвращает сигнатуру и задаёт чистую 5-таб IA. Источник дизайна: `docs/wireframes/design-board.html` (charCard). Разбор разрыва: `docs/specs/2026-06-12-designboard-vs-built-gap.md`.

## Цель
Сделать так, чтобы TMA визуально и структурно стал ОДНИМ продуктом, попадающим в дизайнборд: чистая навигация без дублей + витрина карточек-персонажей. Без новой тяжёлой инфры — на существующем бэкенде.

## Финансовая модель (резолв основателя 2026-06-12 — рамка, не строится целиком в A)
- **Фаза 1 (сейчас):** AIAG = оператор №0. Сеет официальных агентов-персонажей на ТЕКУЩЕМ общем рантайме. Массы (~$20, шара) их **используют/арендуют** с первого дня.
- **Массы НЕ создают/не конфигурируют** агентов — берут готовых. Кнопка карточки = «Арендовать/Использовать», не «Создать».
- **Фаза 2 (позже, премиум):** внешние платные операторы разворачивают **дедик-Hermes** (~16GB-бокс + провижининг), создают своих и сдают/продают. Тогда же открываются операторские каталоги Модели/Скиллы/MCP/Тузы/Базы.

## Объём под-проекта A (что СТРОИМ)
1. **5-таб нижняя навигация** с непересекающимися зонами.
2. **Агенты (главная)** — мессенджер-инбокс «моих» агентов.
3. **Маркет** — витрина карточек-персонажей (re-skin существующего templates-маркета).
4. **Дэшборд** — существующий биржевой хаб, переименован во вкладку.
5. **Кошелёк** — баланс/пополнить/леджер (существующее, собрано в таб).
6. **Аккаунт** — профиль/тариф/согласия/доход/выход.
7. **Полная charCard** — компонент карточки-персонажа из дизайнборда.

### НЕ в A (отдельные под-проекты)
- B: стрим-чат на «Агенты». C: группы + общая память. Фаза 2: операторские каталоги + дедик-Hermes + создание для операторов. Создания для масс нет вовсе.

## Навигация — 5 табов, границы

| Таб | Роут | Содержимое | Граница (НЕ дублирует) |
|---|---|---|---|
| Агенты | `/agents` | инбокс моих агентов → тап → агент (run/history) | — |
| Маркет | `/market` (станет витриной агентов) | карточки-персонажи для аренды | не показывает баланс |
| Дэшборд | `/dashboard` (новый) | командный центр: обзор-глазом, шорткаты, баланс-чип | только ОБЗОР, не операции |
| Кошелёк | `/wallet` (новый, из profile) | баланс, пополнить TON, леджер, кошельки | не настройки |
| Аккаунт | `/account` (новый, из profile) | профиль, тариф, 152-ФЗ, доход автора, выход | не операции с деньгами |

Принцип Дэшборд↔Кошелёк: **Дэшборд = смотреть, Кошелёк = делать.** Активный таб — амбер-индикатор (DESIGN.md). Один амбер-CTA на экран.

⚠️ Текущие роуты `/templates`, `/skills`, `/profile`, `/profile/topup`, `/profile/income` переезжают/переименовываются — см. «Миграция роутов» ниже.

## Экраны

### 1. Агенты — мессенджер-инбокс (главная)
- Список «моих» агентов строками-диалогами: портрет(оттенок) + имя + время последнего прогона + превью последнего ответа + бейдж непрочитанного (если есть).
- Тап по строке → экран агента (СЕЙЧАС = существующий run/history+композер; в фазе B апгрейд в стрим-чат). Бэкенд не трогаем.
- Секция **«Группы»** — заглушка с честной пилюлей «скоро» (реальное в фазе C). Можно скрыть, если 0.
- **Empty-state (новичок, 0 агентов):** «У тебя пока нет агентов» + амбер-CTA «Взять в Маркете →» (ведёт на `/market`).
- На вебе — split-pane (список слева, диалог справа); на мобиле — инбокс→диалог (full-screen).

### 2. Маркет — витрина карточек-персонажей
- **Реализация: re-skin существующего templates-маркета** (`GET /api/tma/templates`). AIAG сеет официальных агентов КАК шаблоны (free или с ценой). Карточки = `charCard`.
- Сегмент-бар сверху: **«Агенты»** активен; «Модели · Скиллы · MCP · Тузы · Базы» — **заблокированы с пилюлей «для операторов»** (видны, но не кликабельны; реальные каталоги — фаза 2).
- Поиск + чипы-категории (Все/Контент/Код/SMM/Данные).
- Действие на карточке: **«Арендовать · N кр/мес»** (платный шаблон, существующий rent-flow) или **«Использовать»** (бесплатный, существующий clone-flow). Результат → агент появляется в инбоксе «Агенты».
- ⚠️ Семантика: в фазе A «аренда/использование» = существующий rent/clone (юзер получает работающий экземпляр). Истинное «использование общего инстанса оператора без владения» — фаза 2 (с операторами). Для масс разница невидима: «взял Алису → общаюсь со своей Алисой». Юзер НЕ билдит/не конфигурирует — берёт готовую.

### 3. Дэшборд
- Существующий хаб `agents/page.tsx` (баланс-хедер + сетка 2×4 + рейлы) переезжает на роут `/dashboard`, таб «Дэшборд». Сетка-шорткаты ведут в Маркет/Кошелёк/Аккаунт/Агенты. Лента «Шаблоны недели» = витрина из Маркета (скрыта при 0).

### 4. Кошелёк
- Баланс (mono, ÷100), «Пополнить» (TON, существующий topup), история движений (леджер `/api/tma/ledger`), привязанные кошельки + ton-proof статус. Собирается из текущего profile + topup.

### 5. Аккаунт
- Профиль (Telegram-имя/аватар), **тариф** (Шара ~$20 / Оператор — заглушка «фаза 2»), согласия 152-ФЗ/ToS, **доход автора** (если оператор — существующий `/me/author-income`), выход.

## Компонент: charCard (полная карточка-персонаж)
Восстановить из дизайнборда (сейчас выхолощена до плитки):
- Портрет с per-character OKLCH-оттенком (`hueFor`) + **live-дот** (пульс) + видео-луп если есть (как уже добавлено).
- Имя + **бейдж модели** inline.
- Роль + **автор** (@handle / «официальный»).
- **Строка-характер** (личность) — `ctrait`. ГЛАВНАЯ потеря, вернуть.
- **Статы**: запусков · ★рейтинг · цена (mono). Демо-данные честно метить «демо», пока нет реальных.
- Действие: «Арендовать/Использовать».
- Голо-эффект (фольга+тилт) сохранить.
- Один компонент для Маркета и инбокса (в инбоксе — компактный вариант).

## Миграция роутов (чтобы не плодить дубли)
- `/agents` остаётся главной, но СОДЕРЖИМОЕ меняется: хаб → инбокс. Старый хаб → `/dashboard`.
- `/market` (был каталог моделей) → станет витриной агентов; каталог моделей уезжает в операторский under-сегмент (заблокирован).
- `/templates` → сливается в `/market` (агенты-витрина). Старый `/templates` редиректит/удаляется.
- `/skills` → операторский сегмент (заблокирован в A).
- `/profile`, `/profile/topup`, `/profile/income` → разносятся в `/wallet` + `/account`.
- BottomNav: 5 табов (Агенты/Маркет/Дэшборд/Кошелёк/Аккаунт). Удалить старые дубли-входы (CatalogNav сегменты Шаблоны/Модели/Скиллы — пересобрать под операторский сегмент Маркета).

## Бэкенд — что переиспользуем (без новых таблиц в A)
- `GET /api/tma/agents` (инбокс), `GET /api/tma/agents/[id]` (диалог-экран).
- `GET /api/tma/templates` (Маркет-витрина), `clone`/`rent` (взять агента).
- `GET /api/tma/wallet`, `topup/*`, `GET /api/tma/ledger`, `wallet/proof-payload`, `wallet/link`.
- `GET /api/tma/me/author-income` (Аккаунт).
- Новое в A: НЕТ money-path/схемы. Только UI + роут-реструктуризация + «последний ответ» для инбокса (можно из последнего `agent_runs.output`, уже есть).

## Зависимости / на основателе
- **Контент-посев:** AIAG-официальные агенты-персонажи (Алиса/Макс/…) как шаблоны — портреты (присылаешь) + спека + цена. Без них Маркет пуст (но empty-state честный).
- Тариф «Оператор» — заглушка до фазы 2.

## Критерии готовности A
- 5 табов работают, без дублей-имён и мёртвых ссылок (проверка по форензик-списку).
- Маркет рендерит полные charCard (характер+статы+автор) — не плитки.
- «Взять агента» из Маркета → появляется в инбоксе «Агенты».
- Дэшборд/Кошелёк/Аккаунт разнесены без пересечений.
- typecheck 0, деплой, верификация на проде.
