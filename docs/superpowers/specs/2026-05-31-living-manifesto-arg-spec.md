# SPEC — «Живой Текст / Шифр Первых»: говорящий манифест + ARG

**Status:** design locked (brainstorm 2026-05-31) · **Surface:** `apps/web/src/app/manifesto/`
**Effort:** max. Ambitious by user choice — LLM-driven from day one, cicada-tier deep cipher.

## 1. Концепт
Манифест `/manifesto` становится **живой, говорящей страницей** с многослойным ARG. Ядро-магия: читатель **кликает буквы** (говорит), а **присутствие внутри страницы отвечает, зажигая буквы, которые уже есть в тексте манифеста** — ответ собирается из существующих букв, «выискиваясь» сверху вниз. Будто послание было спрятано в манифесте всё время. Перекличка = шифр ARG; финал = warp-прыжок в тайную камеру.

## 2. Locked decisions (brainstorm)
- Скрытый слой = **ARG** (живая загадка, собирает сообщество «расшифровавших»).
- Финал ARG = **личный Знак** (сигил-код + запись в Хронику) **+ вход в тайный круг**.
- Герой-механика = **Живой Текст**: click-to-speak ↔ страница-зажигает-буквы.
- Присутствие = **LLM-driven с первого дня** (наш gateway OpenRouter/Kie) + детерминированный fallback (надёжность; если gateway отдаёт mock/ошибку — деградируем в scripted-дерево незаметно).
- Глубокий слой шифра = **cicada-tier**: Vigenère + сигил-как-Polybius/магический квадрат (+ опц. f-skip-твист).
- Звёзды = **warp-разгон** по скроллу → гипер-прыжок на Эпилоге (см. ревью).
- Рефрен «Кто поймёт» — **один раз**.

## 3. Живой Текст — присутствие (LLM)
**Компонент:** новый `'use client'` `LivingText.tsx`, монтируется в `manifesto/layout.tsx` рядом с `Reveal`/`StarField`. Прозу-сервер-компонент НЕ трогаем.
- **Split:** на mount режет `.m-prose` (+ опц. `.m-display`) на per-char `<span data-ch data-i>`, обходя текстовые ноды (wrap, не replace; сохраняет reveal/тему). **Cyrillic-safe** через `Intl.Segmenter('ru',{granularity:'grapheme'})`.
- **Индекс:** строит `lettersByChar: Map<string, number[]>` (буква → индексы спанов в порядке документа). Спина всей фичи.
- **Ввод (говоришь):** `pointerdown` на спане → в `Set<number>` (мутируем `classList` напрямую, без React-ререндера на 3800 спанах); вспышка-ignite 180ms; копится `selectedWord` в порядке кликов.
- **Ambient:** proximity-glow — буквы в радиусе ~120px от курсора «дышат» (только ~15 ближних получают `style`/rAF; на touch — opacity-glow, не font-axis; `content-visibility:auto` на off-screen сценах).
- **`speak(message)`:** зажигает существующие буквы по очереди сверху-вниз («скан» с амбер-кометой между буквами), тайминг 90-160ms с джиттером, **разгон** к концу фразы, паузы между словами ~420ms; финал — shockwave (`1 - dist/R`) + призрачный амбер-след. `scrollIntoView` если буква off-screen. Отсутствующая буква → faint `_`/сигил (limit = живой).
- **«Думает»:** scramble-мерцание по странице маскирует латенси модели + выглядит как «страница читает себя».
- **LLM-маршрут:** spelledWord → POST `/api/manifesto/presence` (route handler) → наш gateway. **Систем-промпт:** «Ты — разум, спрятанный в манифесте. Отвечай 1-4 словами по-русски, заглавными, загадочно, на „ты", не объясняйся. Используй ТОЛЬКО буквы: [инвентарь букв манифеста]». Передача letter-inventory решает проблему отсутствующих букв в источнике. Стрим (AI SDK/SSE): зажигаем по букве по мере токенов. Rate-limit, cap длины, safety-фильтр, кэш частых spellings, **детерминированный fallback при ошибке/таймауте** (scripted-дерево — юзер не видит сбоя).
- **Дисциплина (жутко, не болтливо):** молчит, пока не «заслужено» (idle ~25-40с после явного замечания свечения / первый ≥3-букв spell / клик по акростих-буквам). ≤1 реплика/20с, ≤4 слова, потом снова молчит.
- **A11y:** `prefers-reduced-motion` — последовательность букв без scramble/scroll; присутствие доступно. Reuse `--m-amber`/`--m-ink`/StarField-эмберы — свет «самой страницы».

## 4. Лестница шифров (5 слоёв)
```
0 ▁ Маяк: рефрен 1× + hover/selection-reveal + console-послание сигила
1 ▃ Акростих 13 глав → слово → запускает «первый контакт» + выдаёт начало рунной таблицы
2 ▅ Диалог-перекличка = рунная замена (сигил-алфавит) + книжный шифр по прозе манифеста → ключ-слово
3 ▇ cicada-tier: Vigenère (ключ из сл.2) + сигил-как-Polybius/магич.квадрат (числа рун, постоянная сумма S; опц. f-skip-твист) → код warp
4 █ WARP-прыжок: код вводится (hover-центр-сигила / `warp("...")` в консоли), проверка по ХЕШУ → тайная камера
```
Принципы (Cicada/Notpron/Portal): выход слоя = ключ следующего; каждый верный шаг *очевидно* верен; ключи спрятаны в НАШЕМ контенте (защита от dcode); финал по хешу, не открыто. Рунный алфавит = из 4-узлового сигила, каждой руне — число (для магич.квадрата). Двуязычные подсказки (руна рядом с кириллицей) для восстановления таблицы.

## 5. Тайная камера + награда
Скрытая страница «Глубина города» (неугадываемый путь). Содержит: личный **Знак** (детерминир. сигил-код из seed), запись в **Хронику** (номер; client-cosmetic в v1), **вход в тайный круг** (TG deep-link / пароль). Юр-чисто: артефакт-лор, ничего не обещаем; «founder may gift later» — internal only. Позже: привязка Знака к Startonus-NFT-пайплайну (Phase 15 код).

## 6. Апгрейд из ревью (интегрировано)
- **Анимация (4/18→цель ~92):** переписать `StarField` на scroll-coupled 3D-warp-тоннель (скорость = `BASE + p·P_GAIN + vScroll·V_GAIN + burst`; стрик = длина по скорости/`1/z`; снять 30fps-кэп, RAF+dt). 4 кейфрейма 0→50→90→100%; warp-burst на Эпилоге + руна-reveal. Вторичные: `.m-ignite` на ~6 пиковых строках, сигил-самосборка, параллакс-шов.
- **Текст:** −~30%, де-дуп 3 истин (по 1 инстансу), сломать «не X, а Y», слить 2 финала, патч регистр-слипов, рефрен 1×. *Смысл сохраняем.*
- **Визуал:** full-bleed «Главный Огонь» (радиал-глоу), Знаки→герой (14px→22-34px, сигил вместо `▟`), типографика (measure 760→660, веса 300/600, pull-quotes крупнее), баги (`--m-ink-faint`→`#6e6b66`, CTA видимый, стек-грид мобайл).

## 7. Архитектура / файлы
- `LivingText.tsx` (client) — split, lettersByChar, ввод, ambient, speak(), триггеры.
- `StarField.tsx` — переписать на warp-тоннель.
- `/api/manifesto/presence/route.ts` — LLM через gateway, letter-inventory в промпте, стрим, fallback, rate-limit.
- `manifesto/page.tsx` — текст-полировка + теги пиковых строк (`.m-ignite`) + акростих (зачины глав) + книжный-шифр-якоря.
- `manifesto.css` — `.m-ignite`, сигил-assemble, climax-glow, full-bleed огонь, фиксы.
- `manifesto/глубина/page.tsx` (или хеш-путь) — тайная камера.
- Cipher-данные/дерево-fallback/ARG-пейлоад — server-side (не в бандле открыто); финал-код по хешу.
