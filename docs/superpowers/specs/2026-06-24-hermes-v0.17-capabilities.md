## 🔑 Критично для НАС (новое в v0.16/v0.17)
1. **Multiplex всех профилей через ОДИН gateway-процесс (opt-in, v0.17)** — снимает наш главный инфра-вопрос (RAM ~300MB×N профилей). Меняет экономику мультитенантности на боксе.
2. **Remote-gateway по OAuth (v0.16)** — это И ЕСТЬ паттерн нашего control-plane; упростит код (тонкий клиент → удалённый Hermes).
3. **Async/background субагенты (v0.17)** — длинные прогоны без блокировки.
4. **Elicitation handler (mid-tool-call подтверждение оплаты/OAuth)** — под агентский кошелёк / approval при найме.
5. **Skills Hub + Automation Blueprints** — готовый рантайм для наших «Навыки» (заглушка) и «Расписания».

## Полный инвентарь возможностей v0.17 (по категориям)
- **Модели:** основной слот (provider auto/openrouter/nous/anthropic/openai/xai/zai/kimi…, base_url, max_tokens, ctx-autodetect из 6 источников) + **11 aux-слотов** (vision, web_extract, TTS, STT, image-gen, compression, approval — по умолчанию auto=основная, переопределяются на дешёвую) + `fallback_providers` + `credential_pool_strategies` (ротация ключей).
- **Тулы (~71 тул / 31 toolset):** файлы (read извлекает .ipynb/.docx/.xlsx, patch fuzzy 9-стратегий, ripgrep), terminal+process, web_search/web_extract, browser-automation (+CDP-gated), memory (batch-атомарно), session_search, todo, **execute_code** (Python вызывает тулы по RPC, zero-context), **delegate_task** (субагенты, background), mixture_of_agents, cronjob, skills_*, vision/image_generate(+i2i)/video/TTS, computer_use, Kanban (9 тулов), мессенджеры/Spotify/HomeAssistant/Feishu.
- **MCP:** stdio+HTTP, каталог в дашборде, **elicitation** (mid-call подтверждение), late-bound тулы (cache-safe), exfil-блокировка.
- **Память:** SOUL.md(персона)+MEMORY.md+USER.md, approval-гейт на запись, Honcho dialectic, внешние провайдеры (mem0/OpenViking/SuperMemory). FTS5 (НЕ вектор).
- **Cron/Blueprints:** cron на естественном языке + Automation Blueprints (без синтаксиса) + Chronos (scale-to-zero).
- **Под-агенты/swarm:** delegate_task (caps/concurrency/depth), background-субагенты, Kanban-оркестрация (разные профили=разные модели/тулы), Gateway-Gateway Relay + Raft.
- **Approval/безопасность:** pre-exec подтверждение+allowlist, Tirith инъекция-скан, secret-redaction, blocklist, write-approval гейт, fail-closed, secure dashboard login.
- **Профили/изоляция:** HERMES_PROFILE (config+memory+скиллы), clone, max_concurrent_sessions, group_sessions_per_user, worktree (git-изоляция), **X-Hermes-Session-Key** (стабильный per-channel id ≤256).
- **Docker/мультитенант:** terminal.backend = local/Docker/SSH/Singularity/Modal/Daytona (serverless+hibernation), **multiplex профилей через 1 gateway (opt-in)**, managed-boot.
- **Каналы (25+):** Telegram(rich-text 10.1), Discord(голос), Slack, WhatsApp(+Business Cloud), Signal, SMS/Twilio, Email, Matrix, Teams, Google Chat, Feishu, iMessage via Photon, и др.
- **REST :8642 / CLI / config:** сессии (CRUD+/chat+/chat/stream SSE+fork), runs (/v1/runs+/events SSE+/stop+/approval), discovery (/v1/models|skills|toolsets|capabilities), /api/jobs/* (cron), OpenAI-совм. /v1/chat/completions+/v1/responses. Auth = статический Bearer API_SERVER_KEY; изоляция = X-Hermes-Session-Key. CLI: hermes profile create/clone, skills install, /undo.
