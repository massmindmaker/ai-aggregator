AIAG TMA — недостающие экраны

Ч/б технический каркас 18 экранов, которых нет в существующем борде (инбокс/маркет-агенты/кошелёк/дэшборд есть в design-board.html). Модель: создатель разворачивает Hermes-инстанс → другие нанимают его (каждый наём = отдельный инстанс с тем же набором скиллов, но персональной изолированной памятью). Клон = свой спек без ключей + память с нуля. Mobile-first 390×844 + desktop 1200 для конструктора и здоровья. Числа/курсы/ID — моноширинным.

плейсхолдер зона / реквизиты primary action ★ — ядро (детально)

A · Создание / развёртывание — создатель разворачивает живой Hermes-инстанс

B · Наём — каждый наём = отдельный инстанс, та же спека, своя изолированная память

C · Маркет-разделы — 5 настоящих разделов вместо одного чипа

D · Память / подключения — память инстанса, MCP-токен, BYOK

E · Модалки — оверлеи поверх затемнённого экрана
