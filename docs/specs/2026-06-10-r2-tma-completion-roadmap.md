# R2 — «ТМА до 108»: roadmap полного доведения (2026-06-10)

> Директива основателя: **довести до 108 по всем параметрам**. Базовая точка: TMA тех 64/108, продукт 57/108 (`2026-06-10-108-reeval.md`). Рамка: **ЦА = AI-агенты**, TMA = «костюм» для е-агента, рантайм (Hermes/OpenClaw/NanoClaw) — сменная начинка со своей памятью. Песочница: Telegram + TON + iNFT. Web-маркет агентов позже выделяется в **Agent Market** (отдельный проект, сейчас не трогаем).

## Решения основателя (зафиксированы 2026-06-10, уточнены второй итерацией)

1. **ПРИОРИТЕТ #1 = полная доработка существующего приложения**: все экраны работают, все пользовательские воркфлоу проходят чётко, дизайн применён полностью. Виральный онбординг — **отложен на потом**.
2. **Агентские траты = агентский кошелёк (TON Agentic Wallets, официальный стандарт TON)** — адаптируем ГОТОВОЕ, НЕ строим x402-аналог и ничего на самом x402 не реализуем (поправка основателя; совпадает с work3-ресёрчем «adopt-not-build»). Кастоди working-key — по-прежнему открытый вопрос перед включением.
3. **Коннекторы рантаймов (OpenClaw и др.) — сначала дополнительный ресёрч/спайк** «насколько просто реально подключить чужого е-агента к TMA», только потом коммит на фазу. Мой ресёрч 10.06 дал поверхности API (см. таблицу ниже) — этого мало, нужен практический спайк подключения.
4. **Кооперативная память — отложена**, направление подтверждено (со временем общая база знаний+скиллов); вернуться с ресёрчем + «мнением ЦА» (агента).
5. **Память агента НЕ строим** — она встроена в рантайм (OpenClaw — MEMORY.md+SQLite hybrid-search; hermes — MEMORY.md/USER.md+FTS5+плагины Mem0/Honcho; NanoClaw — CLAUDE.md+SQLite). В UI — бейдж «память: у рантайма».

**Протокол connect-your-runtime v1**: пресеты поверх существующего generic-коннектора (дефолт-порт, схема auth, health-check `GET /v1/models`); BYO-runtime = 0 комиссии (правило в коде); **монетизационная петля: «подключи свой OpenClaw — модели бери через наш :4000»** (юзер указывает наш gateway как провайдера в своём рантайме); телеметрия из `usage` в `/v1`-ответах. Честные ярлыки: что нельзя удалённо (config OpenClaw, всё у NanoClaw) — показываем инструкцией, не мёртвой кнопкой.

## Фазы R2 (порядок = сначала доработать существующее до «всё работает чётко»)

- **R2.1 ПОЛНАЯ ДОРАБОТКА (текущая)** — бэклог ниже: каждый экран/воркфлоу либо работает end-to-end, либо честно помечен и не дразнит. Включает чат-петлю (ворота основателя) и деньги-доверие (реконсилер пополнений).
- **R2.2 Агентский кошелёк** — TON Agentic Wallets (адаптация готового стандарта); tool-market, где агент платит сам; founder-gate: модель кастоди.
- **R2.3 Спайк коннекторов** — практический ресёрч «подключаем реальный OpenClaw/Hermes к TMA за сколько шагов»; решение о фазе по результату.
- **R2.4 Наблюдаемость+тесты** — C7 (метрики реально инкрементить), money-роуты TMA покрыть тестами, алерты.
- **R2.5 Supply каталога** — 12-15 готовых агентов-персонажей (OKLCH-карты) с пред-прошитыми скиллами.
- **отложено**: виральный онбординг (вернёмся после R2.1); web заморожен до Agent Market, КРОМЕ C1/C2/C3 (платежи чинить до любого трафика).

## R2.1 — Бэклог полной доработки (сверка: user-workflows 03.06 × инвентарь 10.06 × прод)

Группа A — деньги/доверие (первыми):
1. **Реконсилер пополнений (cron)** — сейчас только клиент-поллинг 10 мин; «зачислим в фоне» — ложь, закрыл апку → пополнение зависло (R-04 loss-mode 1).
2. **ton-proof при привязке кошелька реально верифицировать** (сейчас принимается без проверки).
3. **Free-first-run**: либо одноразовый грант (решение fdprice: ~300 кр), либо убрать «бесплатно» из копий. Founder-gate на сумму.
4. **Предсказание цены ДО запуска** («~N кр/прогон» из реальных цен модели, не декорация).
5. Проверить DM-карточку воркера: ₽ → кредиты (флаг J14.1).

Группа B — ядро-цикл:
6. **Чат-петля**: многоходовой диалог (для AIAG-пути через gateway; для BYO — их `/v1`), история сессии, стоимость у сообщения. Стриминг — отдельным дисплей-пассом (биллимый вызов не стримим — R-05).
7. Прогресс «агент работает…» вместо тишины после 202 + понятный фейл-стейт.

Группа C — экраны-сироты/стабы:
8. `/profile/income` (доход автора) — достроить UI поверх живого Wave-1 API либо убрать вход.
9. `/templates/[id]` и `/market/[slug]` — довести PARTIAL до полных.
10. Редактор бюджета агента (значения давно enforced, экрана нет) + редактор tools[].
11. MCP-подключение: каталог пресетов (Notion/Sheets/GitHub) вместо ручного URL+client_id.
12. **Legacy nft/\* снести** (deferred-items: webhook/collections/[slug]/BuyButton) — Phase 16 уже не зависит.
13. Канбан: оставить только для external + честный ярлык R&D.

Группа D — честность копий (где функции нет — не обещать):

16. Decorative-метрики на карточке модели (uptime/p50) — убрать или подключить к реальному health шлюза.
