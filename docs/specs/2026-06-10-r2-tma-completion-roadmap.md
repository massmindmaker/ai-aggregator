# R2 — «ТМА до 108»: roadmap полного доведения (2026-06-10)

> Директива основателя: **довести до 108 по всем параметрам**. Базовая точка: TMA тех 64/108, продукт 57/108 (`2026-06-10-108-reeval.md`). Рамка: **ЦА = AI-агенты**, TMA = «костюм» для е-агента, рантайм (Hermes/OpenClaw/NanoClaw) — сменная начинка со своей памятью. Песочница: Telegram + TON + iNFT. Web-маркет агентов позже выделяется в **Agent Market** (отдельный проект, сейчас не трогаем).

## Решения основателя (зафиксированы 2026-06-10)

1. **Ворота запуска = все четыре**: виральный онбординг · коннекторы рантаймов · tool-market с агентскими тратами · чат-петля.
2. **Агентские траты v1 = сразу x402-on-TON** (НЕ внутренний леджер). Перебивает план work3-v1; кастоди working-key — открытый риск, см. фазу R2.3.
3. **Кооперативная память — отложена**, но направление подтверждено: со временем общая база знаний+скиллов кооперативного е-агента; v1-слот в архитектуре оставляем (skills-маркет уже есть как зародыш), определим состав позже + нужен ресёрч и «мнение ЦА» (агента).
4. **Память агента НЕ строим** — она встроена в рантайм (подтверждено ресёрчем: OpenClaw — MEMORY.md+SQLite/LanceDB hybrid-search; hermes — MEMORY.md/USER.md+FTS5+8 плагинов Mem0/Honcho; NanoClaw — CLAUDE.md+SQLite). В UI — бейдж «память: у рантайма».

## Фазы R2 (порядок = виральность сначала, деньги сразу за ней)

- **R2.1 Виральный онбординг** — 1-тап клон из каталога (имя автогеном, спека из шаблона), полезность в первые 60 сек, предсказание цены до запуска, share-петли: ссылка на шаблон + подарить агента (Phase 16 live) + inline-приглашение. Решает продукт-оси 2 (TTV) и 10 (виральность).
- **R2.2 Чат-петля** — многоходовой диалог со стримингом (SSE через gateway — C4 закрыт; для BYO-рантаймов — напрямую их `/v1`), история сессии, стоимость в строке сообщения (RunTrace-паттерн). Оси 3 (ядро-цикл), 9 (стриминг).
- **R2.3 x402-on-TON v1** — агентский TON-кошелёк + наш фасилитатор (x402-аналога на TON нет — строим свой, work3 R&D); кастоди: предпочтителен Model A (TEE-вендор) по work3-ресёрчу, **founder-gate: выбор вендора/бюджета**; capы агента — наши существующие гейты (on-chain контракт-капы = v2); tool-market с ценами, агент платит сам. Оси 7 (экономическая агентность), 4 (биллинг).
- **R2.4 Коннекторы-пресеты** — OpenClaw (:18789, Bearer, security-варнинг «не выставляй без auth»: CVE-2026-25253/32922) и Hermes (:8642 + deep-link на его админку); бейдж памяти; петля «модели через :4000». Ось 6+3.
- **R2.5 Наблюдаемость+тесты** — C7 (метрики реально инкрементить), money-роуты TMA покрыть тестами, алерты. Оси 10, 11 (сейчас 3 и 4).
- **R2.6 Supply каталога** — 12-15 готовых агентов-персонажей (OKLCH-карты уже в дизайне) с пред-прошитыми скиллами; «холодный старт» маркетплейса. Ось 5 (сейчас 3/9).

Параллельно (не блокирует): aiag-моушн в TMA; web — заморожен до Agent Market, КРОМЕ C1/C2/C3 (платежи web чинить до любого трафика туда).
