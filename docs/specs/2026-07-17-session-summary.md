## Задеплоено (28+ коммитов, tip `d16cc39` / `ad03dd0`)

1. **Кредитный леджер — фикс ~120× оверчардж.** `model_upstreams.price_per_1k_*`
   хранит центы (USD×100), гейтвей читал их как USD и множил на курс ЦБ. Верная
   формула: `costCredits(микро) = round(upstreamCents × markup × batch × caching × 1000)`.
   Markup 1.20/1.25 → **1.8** на всех 76 привязках. Курс ЦБ убран из рантайма
   (`fetchUsdRubRate` не встречается в `dist`). Якорь-регресс: Sonnet 1k+0.5k @1.8 =
   1890 микро (было бы 189000 с багом). Миграции 0056/0057/0058/0059/0061.
2. **Аудио/TTS вырезано целиком.** `/v1/audio/speech` осознанно 503 (fail-closed) —
   TTS никогда не работал (`elevenlabs-tts-hf` без `case 'hf'`, `-kie` без кэпа длины
   input). Три итерации починки вскрывали новые дыры — решение координатора: не чинить
   в этой ветке, откатить к честному fail-closed.
3. **Web↔TMA split, шаг 1-2.** TMA получила свою оргу `agents-market`, свой
   gateway-ключ, свой кошелёк (старт с 0 — раны честно 402 до пополнения), реальные
   капы (миграция 0060). Два тихих фолбэка на прямой OpenRouter закрыты
   (`agent-runner.ts`: 402/401/403/пустой ключ → честная ошибка, не утечка маржи).
4. **Плейграунд + Redis-счётчик.** Fail-closed на неизвестный IP, счётчик перенесён
   в Redis (leak-closure plan Task 5).
5. **A2A-изоляция найма.** Наёмные раны больше не могут делегировать `call_agent` в
   приватный флот владельца.
6. **White-label.** Отображаемое имя апстрим-модели больше не протекает через
   `models.display_name` (Kie-утечка закрыта).
7. **Аудит 3-го круга (12 направлений, 119 находок, 11 P0, 40 HIGH)** — реестр
   зафиксирован, часть P0 закрыта этой же сессией (drizzle-on-prod риск — теперь
   условный запрет вместо догмы), остальное — открыто ниже.

## Открытое (не выдумано — взято из аудита 3-го круга и найденных P0/HIGH)

### Фейковые продукты
- `/v1/embeddings` возвращает 8-мерные векторы из `Math.sin()` и **берёт за это деньги**.
- **Подписку нельзя купить** — чекаут висит на недостижимом мёртвом коде,
  `?upgrade=` никто не читает.
- Плейграунд сам пишет пользователю «Это mock-версия».
- Лендинг продаёт тарифы **Growth 4490₽** и **Business 29900₽**, которых нет в `TIERS`
  ни в коде, ни в БД — платный тупик.
- Обещание **«Free 50₽»** — не начисляется.

### Деньги
- Мост оплата→org-кошелёк отсутствует — оплативший юзер получает **402**.
- Tinkoff env не задан на проде (боевой приём рублей выключен).
- 5 из 6 P0-утечек гейтвея закрыты (план `2026-07-16-gateway-money-leak-closure.md`,
  Task 5 закрыт этой сессией) — 1 остаётся открытой.
- Рефанд-эндпойнт двигает реальные деньги и **не пишет ничего** в аудит-лог.
- Ручка пополнения баланса орги принимает **отрицательные суммы** за голым
  `prompt()` в админке.
- Цены yandex/gigachat в **16×** ниже реальных.

### Инфраструктура
- Чат мёртв из РФ (403) — нужен внешний прокси, ~$5/мес.
- Redis сконфигурирован `allkeys-lru` при 256MB, а BullMQ требует `noeviction`.
- Бэкапы на том же диске, что БД (`/dev/sda1`) — S3-выгрузка закомментированный TODO,
  `archive_mode=off`, 0 слотов репликации → PITR невозможен.
- **39 роут-файлов TMA** (`apps/tg-miniapp/app/api/tma/**`) создают собственный пул
  `postgres()` (`max=10`, `idle_timeout=0`) вместо переиспользования общего пула —
  риск исчерпать `max_connections=97` на проде первым падает money-path.

### Прочее
- Юр-страницы (оферта/условия/конфиденциальность) — черновики с фейковым
  ОГРНИП `0000000000` при живом приёме рублей.
- Подписка без выхода — `expired` никто не пишет, «отмена» = no-op.
- Оплаченный тариф может не активироваться молча.
- API теряет `temperature`/`max_tokens` при проксировании.
- Слаги моделей в доках не существуют в прод-таблице `models` (утечка маржи через
  OpenRouter-fallback, если повторится).
- Двойное списание при stalled-redelivery BullMQ — `markStarted()` без гарда обнуляет
  идемпотентность `settleRun` при `pm2 restart` посреди активного рана (TMA-сторона).

### Долги леджера (из этой сессии)
- Витрина по-прежнему рекламирует TTS (32.4 кр/мин) — товар, который 503-ит.
- Кэш `model:<slug>` не версионирован.
- `policies.ts` сравнивает микро-кредиты с рублями напрямую (единица не приведена).

## Приоритеты (предложение, не решение основателя)

1. **Мост оплата→кошелёк** — без него весь боевой приём денег бесполезен (402 после
   оплаты). Самый большой разрыв между «деньги пришли» и «продукт это видит».
2. **Пул соединений TMA (39 файлов)** — тихий риск, который рано или поздно роняет
   money-path целиком, а не постепенно деградирует.
3. **Убрать/пометить фейковые продукты** (embeddings, недостижимая подписка,
   несуществующие тарифы на лендинге) — либо чинить, либо честно снять с витрины;
   деньги/доверие берутся уже сейчас за не-товар.
4. **Бэкап вне диска БД** — открытый гэп disaster recovery, не блокер работы, но
   единая точка отказа для всей БД.
5. Продолжить сплит web↔TMA (каталог через `/v1/models`, разрыв FK, физический
   сплит БД) — план прописан, `docs/superpowers/plans/2026-07-17-split-web-tma.md`.
