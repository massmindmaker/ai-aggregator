# Недостающие экраны AIAG TMA — wireframe-спека (2026-06-12)

Ч/б навигируемый борд: `docs/wireframes/missing-screens/index.html` (18 артбордов + 4 варианта). Через скилл wireframe-kit. Источник правды по модели: `2026-06-12-product-model-hermes-IA-synthesis.md`.

## Продуктовая модель (уточнение основателя 2026-06-12)
Создатель **разворачивает полноценного e-агента** = реальный Hermes-инстанс на нашем VPS/TimeWeb. Другие юзеры **нанимают** его — каждый наём = **ОТДЕЛЬНЫЙ инстанс (Hermes profile)** с ТЕМ ЖЕ набором скиллов/спеком, но **ПЕРСОНАЛЬНОЙ изолированной памятью** (ключ памяти `(agent_id, наниматель)`). Клон = всё своё (спек без ключей, память с нуля). Это ложится на решение «прокси к реальному Hermes» (profiles, не pod-на-юзера) + наём с памятью per-наниматель.

## Инвентарь недостающих экранов (18)
**Создание/развёртывание (создатель):** 01 AI-builder из слов · 02 Конструктор спека (desktop+mobile: Личность/Модели+aux-слоты/Тузы/MCP/Память) · ★03 Развёртывание инстанса (стэппер Спек→Инстанс→Скиллы→Готов + лог + ресурсы) · 04 Здоровье агента (online/аптайм/нанят/доход) · 05 Публикация (нанимаемость+цена+клон).
**Наём (наниматель):** ★06 Нанять (что получаешь: те же скиллы + своя память + read-only спек + цена) · 07 Провижн инстанса · ★08 Досье нанятого (табы Чат/Память/Спек-read-only; память моя) · 09 Онбординг/free-first-run.
**Маркет-разделы:** ★10 Скиллы · ★11 MCP · ★12 Тузы · 13 Базы знаний (данные скиллов/MCP/тузов уже в коде — AVAILABLE_TOOLS/MCP_PRESETS).
**Память/подключения:** ★14 Управление памятью (факты моно + забыть + очистить) · 15 MCP-токен · 16 BYOK-ключ.
**Модалки:** 17 Нанять (sheet) · 18 Очистить память (dialog) + мини-оверлеи развернуть/ключ.

## Дизайн-решения борда
Строго Ч/Б (структура важнее палитры; бренд/цвет — позже поверх скелета); mobile-first 390×844 (+desktop 1200 для конструктора и здоровья); все числа/ID/порты/профили моноширинным; модалки = оверлей scrim+sheet/dialog; статика без JS. Не дублирует существующие экраны (`design-board.html`).

## Hermes-маппинг в этих экранах
Конструктор (02): чат-модель = один пикер + **aux-слоты** (vision/compression…) в коллапсе; **image_gen/voice — тузы, не слоты модели**. Развёртывание (03) = провижн Hermes profile. Досье нанятого (08) = проксирование Hermes-сессии нанимателя (своя память/история, спек создателя read-only). Память (14) = MEMORY.md-подобный список (FTS, не «вектор»).
