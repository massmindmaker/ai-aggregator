# Инструкция: завести Coinbase CDP + ключ для x402 (для друга)

**Цель:** создать аккаунт **Coinbase Developer Platform (CDP)** и **Secret API Key** — это
ключ, которым наш бэкенд будет оплачивать внешние тулзы поштучно (протокол x402, USDC на
Base). Это НЕ обычное приложение-биржа Coinbase — это **девелоперская платформа (API)**.

> Бесплатно. Реальные деньги для теста НЕ нужны — спайк гоняем на бесплатном testnet.

---

## Шаг 1. Создать аккаунт CDP
1. Открыть **https://portal.cdp.coinbase.com** (именно `portal.cdp.coinbase.com` — Developer Platform).
2. Зарегистрироваться (по email или войти существующим Coinbase-аккаунтом).
3. Если попросит создать **организацию / проект** — создать, назвать например `AIAG`.

> Если увидишь баннер **«Verify your business to go live with payments»** — его можно
> **ПОКА ПРОПУСТИТЬ**. Это нужно для приёма/выплат денег (сторона продавца). Нам для оплаты
> тулзов на testnet верификация бизнеса не требуется. (Понадобится позже для крупного mainnet.)

## Шаг 2. Создать Secret API Key (это и есть «ключ»)
1. В левом меню / настройках проекта найти раздел **«API Keys»** (иногда внутри «Coinbase APIs»
   или в настройках аккаунта справа вверху).
2. Выбрать **Secret API Keys** → **Create / Create API Key**.
3. Имя ключа: например `aiag-x402`. Тип ключа — **Ed25519** (рекомендуется), если спросит.
4. Нажать **Create**.
5. **СКОПИРОВАТЬ И СОХРАНИТЬ ДВЕ ВЕЩИ** (приватный ключ показывается ОДИН РАЗ!):
   - **API Key ID / Key Name** — длинная строка (это `CDP_API_KEY_ID`).
   - **Private Key / Secret** — секрет (это `CDP_API_KEY_SECRET`).
   - Сохранить обе в надёжном месте (менеджер паролей / зашифрованная заметка).

## Шаг 3. (Опционально) Кошелёк + бесплатный testnet
Это мы можем сделать сами по API-ключу, но если хочешь — можно прямо в портале:
- Раздел **«Wallets»** (или «Onchain Tools») — CDP умеет создать **Server Wallet** (для оплат).
- Раздел **«Faucet»** — выдаёт **бесплатные testnet-средства**: для сети **Base Sepolia** —
  немного ETH (на газ) + testnet **USDC**. Этого хватит на весь спайк бесплатно.
- (Хостед-фасилитатор CDP `api.cdp.coinbase.com/.../x402` делает всю блокчейн-часть — настраивать
  его не надо.)

## Шаг 4. Что передать нам (Бобу)
- **API Key ID** + **Private Key (Secret)** из Шага 2.
- ⚠️ **БЕЗОПАСНО** — НЕ в открытый чат/мессенджер. Через менеджер паролей, зашифрованную заметку
  или защищённый канал. Эти два значения = как пароль к трате денег. Если где-то засветились —
  перевыпустить (в портале можно удалить ключ и создать новый).

---

## Коротко (TL;DR для друга)
1. `portal.cdp.coinbase.com` → регистрация (баннер про verify business — пропустить).
2. **API Keys → Secret API Key → Create** → сохранить **Key ID** + **Private Key**.
3. (по желанию) Faucet → Base Sepolia testnet USDC (бесплатно).
4. Передать Key ID + Private Key **безопасно**, не в открытый чат.

Всё. ~5–10 минут. Реальных денег не требуется (тест на бесплатном testnet).
