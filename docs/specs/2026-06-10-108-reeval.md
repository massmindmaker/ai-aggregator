## 7. Roadmap агентской инфраструктуры (линза «ЦА = агенты»)

Что нужно агенту, чтобы платформа стала его средой развития, в порядке разблокировки:

- **P0 — Память через РАНТАЙМ, не свой слой** (уточнение основателя 10.06): TMA = «костюм» для е-агента; память встроена в подключаемый рантайм (Hermes / OpenClaw / NanoClaw) либо подключается тулзами/MCP, либо покупается. Наша работа = коннекторы рантаймов первого класса + шов передачи памяти (D-5 re-key), НЕ pgvector-слой в TMA.
- **P0 — 1-тап клон**: из каталога шаблонов в работающего агента за один тап (имя автогеном, спека из шаблона). Это и есть «стихийность» для деплоера-человека.
- **P1 — Экономическая агентность v1**: внутренний леджер (work3 Model B v1) — агент сам платит за тулзы из своего бюджета (Firecrawl и т.п.), пользователь не пополняет «карту на каждый чих». Капы уже есть — не хватает спендера.
- **P1 — Рантайм-обнаружение скиллов**: машиночитаемый каталог скиллов/MCP, чтобы агент мог запросить недостающий инструмент сам (с бюджет-гейтом), а не ждать ручной настройки OAuth-URL.
- **P2 — Управляемый Hermes** (≈16GB бокс, спайк-план готов): резидентный рантайм = настоящая автономия вместо stateless-петли.
- **P2 — Вирусная петля передачи**: передача-в-дар (live) + публичные страницы-офферы + рефералка = агент как подарок, распространяющий платформу.

Сквозная честность: web-продукт в текущем виде не должен получать трафик до починки C1/C2/C3 — деньги пользователей будут уходить в никуда.
