## ЧАСТЬ 0. Самое главное одним абзацем
Дизайн у нас **красивый** (флагман-витрина = 89/108), обе темы (тёмная TMA + светлая Web в стиле Studio23) сделаны честно по нашим токенам. **Но реальные экраны-«доски»** (полные раскадровки на 38 экранов) **врут**: показывают функции, которых ещё нет, и рисуют выдуманные цифры («99.9% аптайм», «312 отзывов», «48k запусков», «доход 4300 кр») как настоящие. Главная задача по дизайну сейчас — не «сделать ещё красивее», а **сделать честно**: чтобы каждый экран показывал только то, что есть, а будущее было явно помечено «скоро». Это ровно то, что ты просил: «интерфейс должен соответствовать реальному функционалу».

## ЧАСТЬ 1. Что реально работает сегодня (честная карта)
Наш TMA сегодня — это **лёгкая «мастерская агентов» прямо в Telegram**, ещё НЕ маркетплейс.

### ✅ Работает прямо сейчас (можно показывать как «live»)
- **Вход** через Telegram (безопасный, укреплён в R0/D-8).
- **Создание агента** из 6 шаблонов или с нуля: имя, характер (промпт), модель, бюджет, 4 встроенных инструмента (веб-поиск, калькулятор, генерация картинки, простая память).
- **Запуск агента и переписка** с ним, история прогонов.
- **Выбор «поставщика мозгов»**: либо наш шлюз (с наценкой), либо **свой OpenAI-совместимый адрес+ключ = бесплатно** (наценки нет).
- **Бюджет/лимиты** на агента (день/месяц), списание перед запуском.
- **Пополнение через TON-кошелёк** (подключение, подпись, ожидание подтверждения в сети).
- **Каталог моделей** (~50 штук) для выбора при создании агента.

### 🔨 Наполовину
- **Редактирование агента** — да (имя/промпт/модель/бюджет/инструменты), но нельзя переподключить чужой адрес после создания, нет красивого экрана «характера».
- **Кошелёк** — работает, **но баланс пока в рублях (₽), а по решению — должны быть крипто-кредиты** (миграция D-1 ждёт).

### ❌ Ещё НЕ построено (нельзя показывать как готовое)
- Управляемый Hermes на нашем «облаке» (R&D).
- **Маркетплейс агентов** (клонировать/опубликовать/арендовать у автора) — сейчас «маркет» = только каталог моделей.
- **Скиллы и MCP-серверы** (только 4 жёстко зашитых инструмента).
- Расписания/cron, канбан, x402-инструменты, мульти-модель (чат/картинка/голос/зрение), Telegram-деплой.

### 🎯 Твой целевой путь — статус по пунктам
| Что ты хочешь | Статус сегодня | Честно |
|---|---|---|
| 1. Подключить **своего Hermes** через TMA и общаться | 🟡 Частично | Технически **да** — вводишь адрес `:8642/v1` + ключ, агент идёт к нему. Но UI не называет это «Hermes» и не ведёт за руку. |
| 2. **Управлять** этим агентом | 🟢 Да (базово) | Меняешь имя/промпт/модель/бюджет. Нет тонкой настройки персоны/мульти-модели. |
| 3. Привязать **скиллы / MCP-серверы** | 🔴 Нет | Только 4 встроенных инструмента. Скиллов/MCP нет. |
| 4. Привязать **TON-кошелёк** и пополнить | 🟢 Да | Работает. Но единица — ₽, а надо кредиты. |
| 5. **Оплатить/арендовать агента** в маркете | 🔴 Нет | «Маркет» = каталог моделей, не агентов. Аренды/оплаты автору нет. |

**Вывод по пути:** уже сейчас ты можешь сам пройти 1→2→4 (подключить свой Hermes, настроить, пополнить кошелёк). Чтобы пройти 3 и 5 (скиллы/MCP и покупка агента) — нужна доработка функций (это в дорожной карте R1, не дизайн).

## ЧАСТЬ 3. План улучшений дизайна — по блокам, обе темы
Принцип (решение основателя #3): **две доски.** Доска A = честная, отгружаемая сейчас (скрываем незаготовленное). Доска B = полное видение (всё помечено «скоро/R&D»). Тёмная тема — TMA/янтарь по `/DESIGN.md`; светлая — Web в стиле Studio23 по тем же токенам.

### Приоритет 1 — ЧЕСТНОСТЬ (доска A), обе темы
Для **каждого** экрана-блока:
1. **Убрать или обрамить выдуманные цифры.** Везде, где стоят «99.9%», «312 отзывов», «48k запусков», «доход 4300 кр», «p50 410мс» — либо убрать, либо явный бейдж **«демо-данные / целевой вид»** (приём уже отработан на витрине).
2. **Чат (S08): убрать стриминг-вид** (печать токенов, кнопка «стоп»), заменить на честный асинхронный паттерн: «агент работает… → уведомим». Снять ложный «Firecrawl −3 кр» как live.
3. **Снять «1-й запуск бесплатно»** на обеих досках (механики бесплатного гранта в коде нет).
4. **Статусные ярлыки на КАЖДОМ экране**: `live` / `скоро` / `R&D` — единым компонентом (иконка+слово), чтобы ни один платный поток не упирался в недостроенный экран.
5. **Единый источник стиля**: доски переводим на те же токены, что витрина, + настоящий логотип-цепочка вместо ◆.
6. **Единая навигация** (5 корней на всех поверхностях): Агенты · Маркет · Тулзы · Кошелёк · Профиль.
7. **Валюта = кредиты, не ₽** во всех макетах кошелька/цен (баланс «1 250 кр ≈ 12.5 USDT»), без Stars.

### Приоритет 2 — ЦЕЛЕВОЙ ПУТЬ (доска B, полное видение), обе темы
Дорисовать недостающие экраны, чтобы твоя мечта была спроектирована целиком (с пометками «скоро»):
- **Развилка Hermes**: «свой Hermes» vs «облачный (R&D)» — с понятным сравнением (свой = бесплатно, наш = с наценкой) и шагами подключения по адресу+ключу.
- **Привязка скиллов / MCP** к агенту: экран выбора + поток «подключить MCP (вход OAuth)».
- **Подключение TON-кошелька** (первый раз) + переключение кошельков.
- **Аренда/покупка агента у автора**: карточка агента → «Арендовать · 50 кр/мес» → оплата кредитами → подтверждение; и обратная сторона — экран автора с доходом.
- **Разбор прогона (run-trace)**: «почему это стоило 12 кр» — обучающее окно (шаги, инструменты, токены, стоимость).

### Приоритет 3 — мелкие осевые правки
Фокус-кольца/disabled/hover на всех контролах; контраст подписей персонажей до нормы AA; кросс-фейд переходов между экранами.
