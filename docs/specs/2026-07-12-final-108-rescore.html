Финмодель — 38

  • Из всей задуманной экономики в коде живёт ровно один механизм — наценка на модели. calcCostRub = upstreamUsd × rate × markup × batchDiscount × caching (packages/api-gateway/src/lib/pricing.ts:23-35), markup берётся из model_upstreams.markup (дефолт конфига 1.25). Реализованная маржа честно возвращается заголовками X-AIAG-Charged-Rub / X-AIAG-Upstream-Cost-Rub.
  • Выручка = 0, и это не фигура речи. 0 ранов за всю историю → 0 наценки. 0 аренд → 0 дохода авторов. 0 проданных членств. Юнит-экономика ни разу не была исполнена ни одним юнитом.
  • Единственный фиатный канал сбора денег сломан (см. работоспособность): рубли с карты не зачисляются. То есть рублёвый продукт, ради которого существует РФ-юрлицо, сейчас не умеет принимать деньги.
  • Аренда автору = 0% комиссии — по решению; значит AIAG с аренды не зарабатывает ничего. При нулевом трафике моделей это оставляет ровно ноль источников дохода. Членство (2/10/30 TON) должно было быть вторым — оно не выкачено.
  • Стоимость инфры под managed-Hermes не смоделирована и упирается в железо: ~300-600 МБ резидентно на профиль против VPS на 2 ГБ с пятью pm2-процессами. Ярус «creator за 2 TON» (~$12 разово) не оплачивает даже месяц резидентного профиля — при живом спросе этот ярус убыточен by design.
  • Валютный шов: шлюз считает в рублях (calcCostRub), TMA обязан быть в USD-привязанных кредитах. Пока трафика нет — незаметно; при первом ране это расхождение станет реальным.

Топ-10 приоритетов

Отсортировано по (влияние на деньги и доверие) ÷ (стоимость). Первые три — дешёвые и критические.

  2. Не задавать MEMBERSHIP_NFT_COLLECTION_ADDRESS до релиза фикса #29 и вкрутить в задеплоенный роут явный kill-switch, чтобы мину нельзя было взвести случайно.

Это не demo-ware по качеству кода — это demo-ware по доказательствам. Денежный путь TMA написан на уровне, который я редко вижу в живых проектах: атомарные списания с guard-ами, идемпотентность, серверный вывод namespace памяти, настоящая криптопроверка ton-proof, глобальный дедуп депозитов. И ровно ничего из этого никогда не исполнялось: 0 ранов, 0 наймов, 0 проданных членств, 1 кошелёк, 2 агента — и оба ваши.

Параллельно рублёвый продукт, ради которого существует РФ-юрлицо, не умеет принимать деньги: подпись платежа проверяется корректно, а зачисление заменено строкой // TODO, при том что рабочий обработчик лежит в двух файлах рядом и никем не вызывается. Это не «не успели» — это подключено не туда.

Что это сейчас на самом деле: тщательно отревьюенный, красиво анимированный, экономически безупречный на бумаге двигатель, который ни разу не заводили, стоящий в машине без бензобака. Следующий балл должен зарабатываться не строчками кода, а первой строкой в tg_ledger_entries и первым зачисленным рублём.
