## Управление (JS-хук, уже в AgentCard)
- `onPointerMove` → `--holo-x/y` (0–100%) + `--holo-rx/ry` (±3.5deg/±7deg) + `data-holo-live="1"`; `onPointerLeave/Cancel` → снять всё. PointerEvents покрывают и touch, и мышь — одна ветка кода.
- **DeviceOrientation НЕ используем** (в Telegram WebView Android отдаёт мусор/требует permission на iOS): источник тилта = палец/курсор. Это уже принято в коде — закрепляем как контракт.
- **Idle-фоллбек:** без взаимодействия foil «дышит» (`aiag-holo-drift` 8s, cubic-bezier(.23,1,.32,1)) — карточки живые и без тача. Дрейф останавливается при `data-holo-live` (есть).
- Возврат в покой: transition 240ms по канонической кривой, без bounce (есть).
- **Доработка-перф:** обернуть установку переменных в rAF-троттлинг (1 запись на кадр): `if (raf) return; raf = requestAnimationFrame(() => {...; raf = 0})` — pointermove на Android может стрелять чаще 60Гц.

## Reduced motion (есть, контракт)
`@media (prefers-reduced-motion: reduce)`: `transform: none !important` на карте (в т.ч. hover), `animation: none` на foil, foil opacity → .08, glare → .12. Т.е. остаётся СТАТИЧЕСКИЙ лёгкий foil-оттенок (карточка не теряет коллекционность), но ноль движения. Также отключать дрейф при `document.hidden` не нужно — CSS-анимации браузер сам приостанавливает в фоне.

## Бюджет производительности
- **Только** transform / opacity / background-position. Никаких filter/box-shadow в покадровой анимации (box-shadow — только в 240ms hover-transition, допустимо).
- `will-change` НЕ ставить глобально; допустимо `will-change: transform` только на `:active`/`data-holo-live` карте (1 шт.), иначе на гриде из 10+ карточек съест память на слабом Android.
- Дрейф-анимация — одна (`::before`), 8s период: на гриде 10 карточек это дешёвая GPU-композиция; если профилировка на бюджетном Android покажет <50fps — добавить `content-visibility: auto` на карточки за вьюпортом (бесплатно отключает их слои).
- mix-blend-mode (color-dodge/overlay) — самый дорогой элемент: НЕ добавлять третий blend-слой; при появлении реальных портретов проверить fps заново (blend поверх фото дороже, чем поверх градиента).
- Tilt ограничен ±7deg / perspective 700 — не увеличивать (распад читаемости + переотрисовка соседей).

**Главный экран:** Сверху вниз (тёмная тема по умолчанию, высококонтрастные упрощённые иконки после редизайна 2025): (1) Топ-бар: аватар профиля слева (вход в My Page/UID/настройки) → строка поиска по центру с подсказками горячих тикеров → справа иконки QR-скан/уведомления/поддержка. (2) Сегмент-переключатель вселенных «Exchange / Web3» под топ-баром. (3) Баланс-дашборд: общая стоимость активов моноширинным шрифтом + глаз-тоггл скрытия + дневной PnL + CTA «Deposit». (4) Иконочная сетка шорткатов: ~2 ряда по 4–5 пиктограмм (Deposit, P2P, Earn, Copy Trading, Trading Bots, Rewards Hub, ежедневные подарки и т.п.), последняя ячейка — «More». «More» открывает полный каталог ВСЕХ функций, сгруппированный секциями по категориям; оттуда drag-and-drop выносишь любимые продукты в верхнюю сетку (Personalized App View). (5) Баннер-карусель промо/акций. (6) Настраиваемые виджеты-модули (карта, копитрейдинг, торговый бот, TradeGPT) — переставляются по вкусу. (7) Лента рынков с горизонтальными табами: Избранное / Hot / Gainers / New — строки тикеров со спарклайнами. (8) BottomNav 5 табов: Home / Markets / Trade (центральный) / Earn / Assets (в старых версиях вместо Earn был Derivatives). Ключ к «вместить всё»: домашний экран показывает только персонализированную выжимку, полнота живёт в каталоге «More» и секционных хабах 2-го уровня (Earn разбит на 3 пути Easy/On-Chain/Advanced; My Page с Usage History; Rewards Hub), плюс отдельный режим Bybit Lite для новичков с урезанным UI.

**Паттерны:**
- **Иконочная сетка шорткатов 2×4 + ячейка «Ещё»** — Под балансом — 8–10 пиктограмм самых ходовых функций в 2 ряда, последняя ячейка «More». Это не вся функциональность, а персональная выжимка; остальные десятки функций скрыты за «More». После редизайна 2025 иконки упрощённые, высококонтрастные, монохромные с одним акцентом. _Для AIAG:_ Брать. На главной TMA под балансом кредитов: 1 ряд из 4–5 (на 640px влезает 5) — «Пополнить», «Создать агента», «Шаблоны», «Подарить агента», «Ещё». Иконки line-style на кружках #18181b, hairline-бордер --line, БЕЗ амбер-заливки (амбер только активный/CTA — accent discipline). Подписи 11–12px --ink-muted. Важно: сетка — только для ФУНКЦИЙ; агентов показывать карточками-персонажами, не иконками (анти-паттерн faceless tiles из PRODUCT.md).
- **«More» = полный каталог функций секциями + drag-and-drop кастомизация (Personalized App View)** — Тап по «More» открывает экран-каталог всех продуктов, сгруппированных секциями по категориям. Сверху — зона «мои шорткаты»: пользователь перетаскивает любимые продукты наверх, и они появляются в сетке на главной (с v4.36.0). Так Bybit вмещает 50+ функций без перегрузки главной. _Для AIAG:_ Адаптировать без drag-and-drop (у TMA функций ~10–15, кастомизация — оверинжиниринг). Экран «Ещё» как секционный список: «Агенты» / «Кошелёк» / «Для авторов» / «R&D», каждая строка со статус-пиллом live/скоро/R&D — это идеально ложится на правило UI=reality: незапущенные функции живут в каталоге с честной меткой, а не на главной.
- **Баланс-хедер с глаз-тогглом и одним CTA «Deposit»** — Первый смысловой блок главной — общий баланс крупно, тоггл-глаз скрывает сумму (приватность в публичных местах), рядом единственная заметная кнопка Deposit. Баланс кликабелен → Assets. _Для AIAG:_ Брать почти 1:1. Кредиты крупно в JetBrains Mono (правило all-numerics-mono), глаз-тоггл — критично для Telegram (открывают в транспорте/на людях), единственная амбер-CTA «Пополнить» (правило one primary CTA). Тап по балансу → кошелёк-хаб. Сумма в «кр», никаких контрактов/газа.
- **Двухрежимность Lite / Pro** — Bybit Lite — отдельный упрощённый режим для новичков: one-click действия, пошаговые подсказки, спрятанные про-инструменты; Pro-режим — полный терминал, копитрейдинг, боты, ChatGPT-ассистент. Один аккаунт, два слоя сложности. _Для AIAG:_ Брать как принцип progressive disclosure, не как отдельный режим-переключатель (две версии UI — дорого). Дефолтный TMA = «Lite»: запуск агента в 2 клика; всё «про» (provider picker, BYOK, свой Hermes, бюджеты) — за вкладкой/аккордеоном «Расширенные» в настройках агента. RU-аудитория Telegram нетерпелива к конфигам — это прямое попадание в персону non-technical user из PRODUCT.md.
- **Лента с горизонтальными табами (Избранное / Hot / Gainers / New)** — Вместо отдельных экранов под каждый срез рынка — один блок-лента на главной с табами-чипами; смена таба меняет содержимое ленты на месте. Избранное наполняется звёздочкой из любого места приложения. _Для AIAG:_ Брать для каталога агентов на главной: чипы «Популярные / Новые / Топ запусков / Мои» над лентой character-карточек. Активный чип — амбер-пилл с чёрным текстом, неактивные — ghost с --line. Скролл-контейнер чипов горизонтальный (на 640px влезут все 4). Это закрывает требование «collectible-card language в ГЛАВНОМ каталоге».
- **Секционные хабы 2-го уровня (Earn → 3 пути, My Page, Rewards Hub)** — Перегруженные домены выносятся в хаб-экраны: Earn реорганизован в 3 явных пути (Easy Earn / On-Chain Earn / Advanced Earn) + Earn Profile с idle/invested активами; My Page собирает профиль + Usage History; Rewards Hub — все бонусы. Главная ссылается на хаб одной иконкой. _Для AIAG:_ Брать. Прямой аналог: экран «Создать агента» = хаб из 3 карточек-путей (подключить свой Hermes / из шаблона / с нуля) — ровно как Earn-3-пути; «Кошелёк» = хаб (баланс, мульти-крипто пополнение TON/USDT, бюджеты агентов, история списаний = аналог Usage History). Каждая карточка пути: заголовок + 1 строка описания + пилл сложности «просто/про».
- **Bottom sheets для быстрых действий** — Выбор сети депозита, тип ордера, фильтры — слайд-ап шторки поверх контекста вместо новых экранов: пользователь не теряет место, где находился; закрытие свайпом. _Для AIAG:_ Уже канон DESIGN.md (modal/bottom-sheet slide-up). Применять для: выбора крипты при пополнении (TON/USDT/ETH/SOL), provider picker при создании агента, подтверждения цены перед запуском. Шторка #111114, drag-handle, heavy shadow разрешён (единственное место по DESIGN.md). На 640px desktop-вебвью Telegram шторку ограничить той же max-width по центру.
- **Переключатель вселенных «Exchange / Web3» в топ-баре** — Один сегмент-контрол наверху главной переключает два разных продуктовых мира (CEX и Web3-кошелёк) с разными главными экранами, не плодя табы в BottomNav. _Для AIAG:_ НЕ брать сейчас. У TMA одна вселенная (маркетплейс агентов), BottomNav из 5 табов уже разводит каталог/моих агентов/кошелёк. Двойной контекст наверху добавит когнитивную нагрузку без выгоды. Запомнить на будущее: если появится второй мир (например, web-аггрегатор внутри TMA), это решение лучше, чем 6-й таб.
- **Баннер-карусель промо (дозированно)** — Одна горизонтальная карусель баннеров между шорткатами и лентой; авто-скролл, точки-индикаторы. Bybit держит её компактной (~80–100px), не превращая главную в витрину акций. _Для AIAG:_ Адаптировать до ОДНОГО статичного слота «featured»: агент недели / новый шаблон, с 2px амбер featured-ring из DESIGN.md вместо пёстрого баннера. Карусель из акций — путь к anti-reference «crypto-neon-casino», для RU Telegram-аудитории и так перекормленной крипто-промо это минус доверия.

### Binance mobile app (2025–2026, включая редизайн «UI Refined» с flexible layout, июнь 2025)

**Главный экран:** Сверху вниз (Pro-режим): (1) Хедер: аватар/Account Center слева (внутри — переключатель Lite/Pro), поиск, иконки уведомлений/QR. (2) Баланс-карта: общий баланс с глазком «скрыть», кнопка Add Funds (deposit / P2P / карта); в редизайне — фиксированный Asset Performance Overview (динамика портфеля по таймфреймам). (3) Сетка шорткатов: до 7 кастомных иконок сервисов + кнопка [>]/More Service, открывающая полный каталог всех функций; [Edit] — добавление (+), удаление (−), перестановка, Reset к дефолту. (4) Фиксированные баннеры (онбординг, кампании, Launchpool) и бегущие тикеры — их двигать нельзя. (5) Зона виджетов (flexible grid, до 8 штук): добавляй/удаляй/перетаскивай/меняй размер — рыночные данные, тренды цен, сентимент; строго между шорткатами и фидом. (6) Маркет-лента: табы Favorites / Hot / Alpha / New / Gainers / Losers / 24h Volume / Market Cap, пары с 24h-изменением. (7) Бесконечный фид Square: Discover / Following / News / Academy / Live. (8) BottomNav 5 табов: Home · Markets · Trade · Futures · Wallets(Assets). Принцип «много функций»: на главной только 7 шорткатов, остальные ~100 сервисов спрятаны за More — пользователь сам собирает свою главную. Lite-режим выкидывает всё: остаётся баланс, простые buy/sell/convert и базовый Earn, без кастомизации.

**Паттерны:**
- **Сетка шорткатов 7 + More/Edit** — На главной максимум 7 иконок сервисов в один-два ряда; кнопка [>]/More открывает полный каталог всех функций по категориям. Режим Edit: тап [+] добавляет, [−] убирает, drag меняет порядок, Reset возвращает дефолт. Жёсткий лимит 7 заставляет приоритизировать и держит главную чистой при сотне функций. _Для AIAG:_ Брать частично. У TMA пока нет 100 функций — полная кастомизация преждевременна. Но паттерн «жёсткий лимит видимых действий + каталог за More» полезен: ряд из 4–5 круглых иконок-действий под баланс-картой (Создать агента, Из шаблона, Пополнить, Мой Hermes) на #18181b с амбер-иконкой только у одного primary-действия (правило один амбер CTA). При 640px ряд из 5 иконок ~56px дышит свободно. Edit-кастомизацию отложить до реального роста числа функций; сейчас достаточно статичного ряда — RU-аудитория Telegram привыкла к такому в банковских приложениях (Тинькофф/Сбер используют тот же паттерн).
- **Lite / Pro переключатель режимов** — Один тумблер в Account Center мгновенно меняет весь интерфейс: Lite = только купить/продать/конвертировать + баланс + базовый Earn, без стакана, графиков, кастомизации; Pro = полный набор (Futures, P2P, Margin, виджеты). Данные и аккаунт общие, переключение без перезагрузки. _Для AIAG:_ Самый релевантный паттерн для AIAG: ЦА раздвоена так же (нетехнические TG-юзеры «агент в 2 клика» vs power-users с BYOK/своим Hermes). Вместо глобального тумблера — прогрессивное раскрытие: дефолтный «Lite»-вид (каталог персонажей, запуск, баланс в кредитах) + секция «Для продвинутых» / тумблер «Режим разработчика» в профиле, открывающий provider-picker, MCP, бюджеты, BYOK. Не делать два отдельных UI (дорого поддерживать на этапе R1) — делать скрытие продвинутых блоков одним флагом. Это же решает правило UI=reality: R&D-фичи живут только в Pro-слое с честными лейблами.
- **Баланс-карта сверху + Add Funds** — Первый блок под хедером — общий баланс (с глазком приватности) и кнопка пополнения с выбором способа (deposit, P2P, карта). В редизайне дополнен фиксированным баннером динамики портфеля по таймфреймам. _Для AIAG:_ Брать напрямую. Карта на #111114 с балансом в кредитах (JetBrains Mono, крупно), глазок-скрытие (привычно RU-юзерам из банков), одна амбер-кнопка «Пополнить» → шит выбора TON/USDT (TON Connect + HOT Wallet). Вместо «динамики портфеля» — расход за сегодня/неделю по агентам (mono, мелко). Это и есть один канонический кредит-юнит из PRODUCT.md: никаких контрактов/газа на карте.
- **Маркет-лента с табами (Hot/Gainers/New…)** — Горизонтальные табы-чипы переключают одну и ту же списочную область: Favorites, Hot, New, Gainers, Losers, Volume. Лёгкое переиспользование одного списка под разными сортировками — создаёт ощущение живого рынка. _Для AIAG:_ Адаптировать под каталог агентов: чипы «Популярные / Новые / Топ по запускам / Мои» над лентой карточек-персонажей. Важно не копировать таблично-тикерный вид (анти-референс: faceless function tiles) — внутри остаются collectible character cards с пер-персонажными OKLCH-оттенками. Чипы — pill-формы, активный = амбер-текст/индикатор, не амбер-заливка.
- **Фиксированные баннеры + flexible-зона виджетов (до 8)** — Редизайн 2025: середина главной — сетка виджетов, которые юзер добавляет/двигает/ресайзит (до 8), но баннеры кампаний и тикеры закреплены платформой и не двигаются. Баланс контроля юзера и гарантированных слотов под коммуникацию платформы. _Для AIAG:_ Виджет-кастомизацию не брать (оверкилл для 640px одноколоночного TMA и текущего объёма функций). Взять идею «фиксированный платформенный слот»: один закреплённый баннер-слот под балансом для честных анонсов (новый шаблон недели, статус live/скоро) — hairline-карта 1px --line, без градиентного AI-slop. Один слот, не карусель.
- **Square-фид (Discover/News) внизу главной** — Под маркет-лентой — бесконечный контентный фид с табами (посты сообщества, новости, академия, лайвы), удерживающий юзера в приложении. _Для AIAG:_ Не брать сейчас. Контентного производства нет, фид станет мёртвой зоной (нарушение UI=reality). Низ главной у TMA лучше отдать ленте каталога агентов — она и есть наш «фид». Вернуться к идее, только когда появятся публикации авторов шаблонов (лента «новые шаблоны от авторов» — органичный аналог).
- **BottomNav 5 табов с центральным действием** — Home · Markets · Trade · Futures · Wallets — пять постоянных табов; Trade/центр — главное транзакционное действие. Каждый таб — самостоятельный стек с под-меню. _Для AIAG:_ У TMA уже 5 табов — паттерн совпадает. Маппинг по логике Binance: Главная (баланс+шорткаты+рекоменд.) · Каталог (= Markets, лента персонажей с чипами) · Создать (центр, = Trade, главное действие — амбер-акцент иконки) · Мои агенты (= Futures/позиции: запущенные агенты, расход, бюджеты) · Кошелёк (= Wallets: кредиты, пополнение, история). Активный таб = амбер-индикатор по DESIGN.md.

### Telegram Wallet (TON Space) + Tonkeeper + Revolut 8.0/10

**Главный экран:** Общая блочная схема всех трёх (сверху вниз): (1) компактный header — аккаунт/адрес-свитчер + иконки настроек/сканера, никакого hero; (2) КРУПНЫЙ баланс по центру (одна цифра в фиат-эквиваленте, моноширинный, вторичная строка — нативная валюта/адрес); (3) action row — 3-5 круглых/pill кнопок с иконкой+подписью (Wallet: Добавить/Отправить/Получить/Обменять; Tonkeeper: Send/Receive/Scan/Swap/Buy; Revolut: Add/Move/Details + виджеты) — это ЕДИНСТВЕННЫЙ блок крупных CTA; (4) опционально 1 узкий промо-баннер/карусель (dismissible); (5) вертикальный список активов-строк: иконка 40px + имя/курс слева + сумма (моно) справа, ~56-64px высота строки — список и есть «контент» экрана; (6) история транзакций или табы (Активы/Коллекционные) ниже сгиба. «Много функций» решается НЕ на главном: Revolut — отдельный Hub-экран со всеми продуктами, сгруппированными по категориям + pull-down smart-поиск + пин/анпин фич на главный; Wallet/Tonkeeper — всё вторичное живёт в bottom-sheet'ах и внутри строк списка (стейкинг = строка «Earn» среди токенов, а не отдельная кнопка). Итог: главный экран = баланс + 3-5 действий + один скроллируемый список; всё остальное за 1 тап (hub/щит «Ещё») или за жестом (поиск).

**Паттерны:**
- **Balance-first + action row** — Баланс — единственный крупный элемент экрана (типографика делает иерархию, не карточки). Под ним горизонтальный ряд из 3-5 одинаковых кнопок «иконка сверху, слово снизу», thumb-reachable, без вложенных меню. У Tonkeeper при >4 действий ряд горизонтально скроллится; у Wallet ровно 3-4 — остальное в листе. _Для AIAG:_ Шапка кошелька TMA: баланс в кредитах JetBrains Mono 36-48px на #0a0a0b, под ним ряд из 3-4 действий, где ТОЛЬКО «Пополнить» — амбер-fill (#f59e0b, текст #000), остальные (Отправить, История, Бюджет) — ghost с 1px line. На 640px ряд центрируется, кнопки 64-72px. Не превышать 4 — пятое действие в bottom-sheet «Ещё».
- **Asset-row list как тело экрана** — Контент главного — плотный однcolонный список строк 56-64px: аватар + название/подзаголовок + число справа (моно). Нет card-grid'ов: строка дешевле по высоте и даёт 7-8 сущностей на экран без ощущения тесноты. Tonkeeper встраивает в этот же список служебные строки (Earn, баннер W5) — функции выглядят как активы. _Для AIAG:_ Список «Мои агенты» на главном — строки, а не карточки: портрет-монограмма с per-character hue + имя/модель + расход за сегодня (моно) справа. Коллекционные character-cards остаются в каталоге (Маркет-таб), а на главном/кошельке — плотные строки. Служебные строки в том же списке: «Дневной бюджет», «Подключить провайдера» — паттерн Tonkeeper.
- **Hub / «Ещё»-экран вместо перегруза навигации (Revolut)** — Revolut держит десятки продуктов: BottomNav — только 5 базовых табов, а ВСЕ продукты собраны на одном Hub-экране, сгруппированном по категориям (узнаваемые разделы, прозрачная сетка). Главный экран не пытается показать всё — он показывает деньги + любимое, остальное «в одном тапе». _Для AIAG:_ BottomNav 5 табов фиксируем (Главная/Маркет/Создать/Кошелёк/Профиль), а растущие функции (MCP-скиллы, провайдеры, шаблоны, бюджеты, iNFT-перенос) — не плодить табы, а собрать hub-список в Профиле/«Ещё» с категориями и статус-пиллами live/скоро/R&D. Это же решает правило честности UI: hub — место, где видна вся карта продукта с метками.
- **Progressive disclosure: pull-down поиск + bottom-sheets** — Revolut 8.0: smart-поиск появляется только при свайпе вниз — ноль пикселей в покое, autosuggest по транзакциям/получателям/функциям. Wallet/TON Space (как TMA внутри Telegram) уводит все вторичные флоу в нативные slide-up sheets — экран никогда не «уходит» далеко, контекст сохраняется. _Для AIAG:_ В TMA вторичные действия агента (настройки, бюджет, шаринг шаблона) — только bottom-sheet (тёмный #111114, scrim), не отдельные страницы: дёшево по навигации и Telegram-нативно. Поиск по агентам/шаблонам — скрытый, раскрывается жестом/тапом по строке, не занимает место на главном. Для RU-аудитории Telegram sheets — уже выученный жест.
- **Персонализация: пин виджетов/фич на главный (Revolut 10)** — Пользователь сам закрепляет виджеты (карты, любимые получатели, крипта) на домашнем экране и снимает ненужные; перевод любимому получателю = 1 тап с главного. Дефолт — разумный минимум, плотность растёт только по желанию юзера. _Для AIAG:_ V1: «закреплённый агент» — один pinned-агент сразу под action row (портрет + кнопка «Чат» = 1 тап до диалога, метрика dream-path). V2: реордер секций главного. Не делать полноценный конструктор виджетов сейчас — дорого; достаточно pin/unpin агентов. Дефолт для нового юзера: баланс + «Получить агента» (3 пути) + топ шаблонов.
- **Один dismissible промо-баннер, не карусель-казино** — Wallet/Tonkeeper вставляют максимум один узкий баннер (новая фича, стейкинг) между action row и списком; закрывается крестиком и больше не возвращается. Никогда не больше одного конкурирующего промо. _Для AIAG:_ Слот для «Опубликуй шаблон — назначь ренту» или Phase-16 transferable-agent: один баннер, ghost-фон #18181b с 1px line, амбер только в иконке/CTA-тексте (дисциплина акцента). Анти-референс «crypto-neon-casino» прямо запрещает карусели промо — слот строго один.
- **Holographic/foil карточка (simeydotme/pokemon-cards-css) — ⚠️ GPL-3.0** — Принцип слоёв: (1) базовый арт карточки; (2) glare-слой — radial-gradient «блик», blend-mode overlay/screen; (3) foil-слой — текстура/повторяющийся градиент радуги с mix-blend-mode: color-dodge; (4) JS pointermove пишет CSS-переменные (--px/--py — позиция блика в %, --rx/--ry — углы), слои читают их в background-position и transform: rotateX/rotateY (perspective на родителе); (5) transition на возврат в покой. Всё на transform/opacity/background-position — GPU-дёшево. _Для AIAG:_ ЛИЦЕНЗИЯ: GPL-3.0 — копировать код в проприетарный TMA НЕЛЬЗЯ (вирусная). Но техника (слои+blend+CSS-переменные) не копирайтится — реализовать с нуля свой React-хук: onPointerMove → setProperty CSS-vars на карточке, 2 псевдоэлемента ::before (glare) / ::after (foil). Адаптация под DESIGN.md: вместо радуги — амбер-голографика в OKLCH per-character hue (duotone-градиент персонажа + амбер-блик), интенсивность ~10-15% поверхности; featured = поверх aiag-featured-ring. Только для character-cards в каталоге (сигнатурный язык), не глобально; touch: на мобиле блик от deviceorientation или лёгкая авто-анимация; полный off при prefers-reduced-motion; ease cubic-bezier(.23,1,.32,1), без bounce.
