# AIAG TMA — критический разбор интерфейса (108) + конкурентный синтез

Основано на ресёрче 6 конкурентов и текущих вайрфреймах (`docs/wireframes/tma/`).

## Конкурентный синтез (паттерн → кто делает → наш ход)
| Паттерн | Кто | Наш ход |
|---|---|---|
| **Usage/runs как соц-доказательство №1** | OpenRouter (rankings), Replicate («71.4M runs»), GPT Store (conv. count), agent.ai (uses), HF (downloads/likes) | runs-count крупно на каждой карточке агента и модели; сорт «популярное за неделю» по умолчанию |
| **Per-route строки (цена/latency/throughput/uptime)** | OpenRouter | бейдж «дешевле/быстрее» + uptime на карточке модели |
| **Фасетный фильтр как bottom-sheet** | OpenRouter, HF | лист-фильтр (модальность/контекст/цена/возможности) |
| **Run-страница = форма ввода + инлайн-вывод** | Replicate, agent.ai | у агента-задачи: типизированная форма + вывод под ней (не только чат) |
| **Conversational create + Configure-форма** | GPT Store, Poe | путь «опиши агента словами» + форма для про |
| **Tappable starter-prompts на карточке** | GPT Store | подсказки-кнопки → запуск в один тап |
| **Clone-to-remix / «форкнуть агента»** | agent.ai | кнопка «Клонировать» на детали агента |
| **Knowledge base (RAG) как поле создания** | Poe, GPT Store, agent.ai | поле «База знаний» (файл/текст) |
| **Капабилити-тогглы (web/vision/code/tools)** | GPT Store | расширить тогглы создания |
| **Галерея примеров на детали модели** | Replicate | примеры вывода на карточке модели |
| **Автор как объект 1-го класса / профили** | agent.ai, GPT Store, Poe | агент-маркетплейс с авторами + «ещё от автора» |
| **Per-agent capped TON-кошелёк** | Virtuals, TON Agentic Wallets | агент тратит из выделенного TON-лимита; основной кошелёк — у юзера |
| **Минт NFT на «graduation» (по достижению)** | Virtuals | Startonus-NFT по майлстоуну расхода/ранов |
| **AVOID: bonding-curve токен на агента, ранк по market-cap** | Virtuals | TON только как pay-for-compute, не «акция агента» |
| **AVOID: пустой client-render каталог** | OpenRouter | у нас статик-ген — ок |
| **AVOID: credit-wall до первого запуска** | agent.ai | первый прогон агента — бесплатно |

## 108-балльный разбор (9 осей × 12) — текущие вайрфреймы
| Ось | Балл | Комментарий |
|---|---|---|
| 1. IA / навигация | **8** | 4 вкладки ясны, но «Агенты» = только МОИ; нет маркетплейса агентов |
| 2. Визуальная иерархия | **9** | тёмно-амбер чисто, карточки консистентны |
| 3. Онбординг / первый запуск | **6** | один слайд; нет пути «от пусто к первому агенту» |
| 4. Ядро: создание агента | **8** | 3 пути + форма; нет conversational, knowledge, run-страницы |
| 5. Маркет / дискавери | **7** | список+чипы+деталь; нет фасет-листа, route-бейджа, примеров, сорта по usage |
| 6. Доверие / соц-док | **7** | рейтинг+кол-во запросов есть; нет runs-первым, авторов, uptime |
| 7. Крипто / платежи | **7** | TON/USDT, TON Connect, минт; нет capped-кошелька агента, метра расхода, free-first-run |
| 8. Мобайл / Telegram-fit | **9** | телефон-фреймы, bottom-nav, sheets; нет горизонт. trending-рядов |
| 9. Контент / empty/error | **8** | модалки успех/ошибка/удаление, пустые есть |
| **Итого** | **69 / 108** | крепкий скелет; провалы — дискавери агентов, run-UX, conversational-create, крипто-кошелёк агента, trust-сигналы |

## Топ-улучшения (приоритет)
**P1 — высокий эффект (строю в v2):**
1. **Маркетплейс агентов** — отдельный экран: trending/featured/категории/автор + runs-count (все 6 конкурентов это имеют; у нас вкладка «Агенты» = только свои).
2. **Run-страница агента** — форма ввода + инлайн-вывод (Replicate/agent.ai) + starter-prompts + «клонировать».
3. **Создание — conversational** путь («опиши словами») + поля knowledge + богатые капабилити-тогглы.
4. **Маркет** — bottom-sheet фильтр + сорт по usage; **деталь модели** — бейдж «дешевле/быстрее», uptime/latency, примеры вывода.
5. **Крипто-натив** — у агента **выделенный TON-лимит** (метр расхода), первый прогон бесплатно.

**P2 — позже:** профили авторов + «ещё от автора»; NFT-«graduation» по майлстоуну; горизонт. trending-ряды.

**Гард-рейлы (из Virtuals AVOID):** TON = оплата компьюта/топап, НЕ tradable-«акция агента»; ранк по реальному usage, не по цене/хайпу; первый запуск без credit-wall.
