## Что теперь умеет продукт (для пользователя)
При создании агента появился выбор **«🌐 Свой провайдер / ключ — 0 комиссии»**:
- Выбираешь провайдера из списка (OpenAI · Anthropic · Google · DeepSeek · Mistral · Groq · OpenRouter · **Custom** — любой OpenAI-совместимый URL, включая свой Hermes за прокси).
- Вводишь **свой ключ** → он шифруется и сохраняется → агент ходит через выбранного провайдера.
- **Комиссия 0** — платишь напрямую своему провайдеру (как и обещано в правиле «свой ключ = бесплатно»).
- Кнопка «Проверить соединение» работает и для каталожных провайдеров.

Это закрывает **дырку когерентности**: обещание «свой ключ = 0 комиссии» раньше было в текстах, но через интерфейс недостижимо. Теперь достижимо. И это первое звено пути мечты: *подключи провайдера → управляй → кошелёк → плати только за своё*.

## Money-correct поправка к авто-плану (важно)
Авто-план рекомендовал «Вариант A» (через новую колонку `provider_id`), но у воркера эта ветка **биллится с наценкой** (`isExternal:false`) — что нарушило бы твоё правило «свой ключ = 0». Как руководитель я провёл BYOK через **уже проверенную ветку `external_openai`** (`isExternal:true` → 0 комиссии). Итог: правило соблюдено, **живой денежный код воркера и `settleRun` не тронуты вообще**.

## Проверено (адверсариально, 2 ревью)
- ✅ **Деньги/корректность:** UI → `provider_id` → бэкенд ставит `connection_type='external_openai'` и **НЕ** ставит `agents.provider_id` → воркер идёт по ветке B → `isExternal=true` → `settleRun` пропускает списание → **0 комиссии**. Воркер/деньги не изменены. Старые пути (наш шлюз + шаблоны) работают как раньше.
- ✅ **Безопасность:** новый эндпоинт авторизован (`x-tma-user-id`); все запросы — prepared statements; URL «Custom» проходит SSRF-щит; URL известных провайдеров резолвится **на сервере** (клиент не может подменить); ключ шифруется AES-256-GCM, хранится только хвост-4; бренд не утекает.
- ✅ **Typecheck:** tg-miniapp зелёный.
- 🔧 **Найден и пофикшен латентный баг:** колонки `external_api_key_hint` не было ни в одной миграции (только в комментарии). На проде 0 агентов → баг мог быть скрытым. Добавлена идемпотентная миграция `0027` (`ADD COLUMN IF NOT EXISTS`).
