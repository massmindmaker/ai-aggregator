# Дизайнборд (SoT) vs построенное — разрыв интерфейса — 2026-06-12

> Запрошено основателем: «картинки интерфейсы в дизайнборде мобильные и то что есть — два разных приложения, как будто не сделано, не попадает в интерфейс». Источник правды: `docs/wireframes/design-board.html` (45 экранов, 10 групп, токены verbatim из DESIGN.md). Сравнение с реально построенным `apps/tg-miniapp`.

## ГЛАВНЫЙ ВЫВОД: построено по ДРУГОЙ спеке (моя ошибка)

Дизайнборд — **единый источник правды** (так и подписан). Его ГЛАВНЫЙ экран (группа B, экраны 03/03b/04/05) = **лента коллекционных карточек-персонажей**: портрет с per-character OKLCH-оттенком, имя + бейдж модели, роль + автор (@handle), **строка-характер** («Дерзкая, режет воду без жалости»), статы (запусков / ★ / цена). Это «сигнатура» из PRODUCT.md: «collectible-character-card language MUST appear in the MAIN catalog».

**А я за 11-12 июня перестроил главный экран в БИРЖЕВОЙ ХАБ** (баланс-хедер + сетка 2×4 иконок + рейлы) — по аудиту `2026-06-11-design-audit-bench.md`, где я бенчмаркал Bybit/Binance. Аудит ПРОТИВОРЕЧИЛ канону, а я пошёл за аудитом, а не за дизайнбордом. Отсюда «два разных приложения».

## Главный экран — рядом

**Дизайнборд (канон, экран 03):**
```
[ Для тебя | Каталог | Мои·3 ]        ← сегмент-лента
ⓘ честная плашка «скоро: лента чужих»
«Рекомендуем тебе · персонажи под задачи»
┌───────────────────────────────┐
│ 🅐 портрет(hue) ● live-дот     │   ← КАРТОЧКА-ПЕРСОНАЖ
│ Алиса  [GPT-5.5]               │
│ Контент-редактор · @ainews     │
│ «Дерзкая, режет воду без…»     │   ← строка-ХАРАКТЕР
│ 48k запусков · ★4.9 · ~6 кр    │   ← статы
└───────────────────────────────┘
  Гриша · Ника · … (лента)
                       (＋ FAB Создать)
```

**Построено (мой хаб /agents):**
```
БАЛАНС  1 240,50 кр   👁     ← баланс-хедер (биржа)
[ Пополнить ]                ← амбер-CTA
┌──┬──┬──┬──┐  сетка 2×4 иконок
│➕│▦│▤│⚡│  Создать/Шаблоны/Модели/Скиллы
├──┼──┼──┼──┤
│⌚│📈│⤴│⋯│  История/Доход/Передать/Ещё
└──┴──┴──┴──┘
📌 закреплённый агент → Чат
Мои агенты (грид монограмм-карточек)
Шаблоны недели (пусто)
```

Это разные продукты: канон — **персонажи-первыми** (витрина характеров), построенное — **деньги-первыми** (крипто-кошелёк). Палитра/токены совпадают (поэтому «похоже по цвету»), но композиция и душа — нет.

## Компонент карточки — что потеряно

| Канон (charCard в дизайнборде) | Построено (AgentCard.tsx) |
|---|---|
| Портрет с hue + **live-дот** (пульс) | портрет/монограмма (live-дота нет) |
| Имя + **бейдж модели** inline | имя + модель строкой |
| Роль + **автор @handle** | роль (автора нет) |
| **Строка-характер** (личность) | ❌ нет — главная потеря сигнатуры |
| **Статы**: запусков · ★ · цена | одна метрика (бюджет/цена) |
| Голо-эффект | ✅ есть (добавил) |

Главное — **пропала строка-характер и статы**: именно они делают карточку «коллекционной», а не «функциональной плиткой» (которую PRODUCT.md прямо запрещает как анти-референс).

## Почему так вышло (честно)
1. Я запустил аудит 2026-06-11, который бенчмаркал биржи и предложил хаб. Аудит **не сверился с дизайнбордом** — и я построил хаб поверх канона, не заметив конфликта.
2. Карточку-персонаж я упростил при первой сборке (монограмма вместо полной charCard), а потом наращивал голо-эффект, но **не вернул характер+статы+автора**.
3. Дизайнборд ни разу не открывали как чек-лист соответствия при сборке — строили по текстовым спекам.

## РАЗВИЛКА (нужно твоё решение)
Это настоящая вилка, не баг:
- **Вариант 1 — вернуться к канону:** дом = лента карточек-персонажей (03), полная charCard (характер+статы+автор+live-дот), биржевой хаб демонтировать/слить в кошелёк. Продукт обретает сигнатуру PRODUCT.md. Минус: баланс/функции прячутся глубже (но это и есть «персонажи-первыми»).
- **Вариант 2 — узаконить хаб:** признать биржевой хаб новым направлением, обновить дизайнборд под него. Минус: теряем «коллекционную» душу, становимся ещё одним крипто-дашбордом (анти-референс PRODUCT.md).
- **Гибрид (моя рекомендация):** дом = лента персонажей (канон 03) ПЕРВЫМ экраном; баланс — компактный чип в шапке (тап → кошелёк), а не целый хаб; сетка функций уезжает в таб «Ещё»/кошелёк. Получаем и сигнатуру, и доступ к деньгам.

Без твоего выбора дальше двигать дом нельзя — иначе снова построю не то.
