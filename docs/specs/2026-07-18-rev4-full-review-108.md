## КОРЕНЬ (один, объясняет 0 платежей / 0 ранов / 0 авторов на проде)

**У продукта нет работающего денежного пути.** Цепочка «оплата → кредиты → вызов модели» разорвана в НЕСКОЛЬКИХ местах одновременно, а цепочка автора «трафик → заработок → выплата» отсутствует архитектурно. Всё остальное (витрина, админка, дизайн) стоит на маркетплейсе, который физически не может провести ни одной транзакции. Прод-нули — не «рано», а структурно.

Кластер подтверждений (независимые агенты сошлись):
- **R1** — моста «оплата Tinkoff/подписка → `organizations.payg_credits`» НЕТ. Платёж кредитует `users.balance`, подписка — `subscriptions.credits_limit`, гейтвей тратит `organizations.*_credits`. Три несвязанных леджера. Оплатил → PAYG=0 → любой `/v1/*` = 402. (подтвердили user+gateway+author+billing/summary self-comment; прод: SUM кредитов по 50 орг = 0)
- **Капы работают только в non-stream `chat.ts`** — 6 из 7 биллящих путей (вкл. streaming) списывают, но daily/monthly/session-капы не двигают. Ключ с лимитом обходится.
- **Stream-путь отдаёт полный ответ и глотает ошибку биллинга** (`sse.ts:94-128`) + апстрим зовётся ДО проверки баланса.
- **Автор-цикл**: `resolveModel()` требует строку `model_upstreams` (approve её не создаёт); адаптера «звонить на endpoint автора» в registry НЕТ (только 5 зашитых провайдеров с нашими ключами); хук `accrue_author_earnings` НЕ портирован в кредитную `aiag_settle_charge_credits` (self-comment «never fired»).

## 🔴 НОВЫЕ находки round-4 (не видел аудит 07-12)

1. **Капы обходятся на 6/7 биллящих путей** (streaming-утечка) — `chat.ts` инкрементит `usd_day`/`cost_month` в 2 строках, остальные пути нет.
2. **Бан не работает на consumer-логине** — `apps/web/src/auth.ts:98-125` не проверяет `isBanned/isActive` (admin-логин проверяет). Забанённый юзер логинится. Кнопка «Бан» в админке реальна → ложное чувство контроля.
3. **18-40с рендер динамических страниц** (мой curl: `/marketplace` 22.8с, `/status` 40с таймаут, `/` 10.2с). Вероятно `force-dynamic` без кеша. Убивает воронку раньше всех грехов.
4. **Автор-цикл мёртв АРХИТЕКТУРНО, не «недоделан»** — нет адаптера вызова endpoint автора; это дыра в дизайне, а не MVP-todo (глубже, чем R4 «ручной gen:catalog»).
5. **3 защитных middleware** (модерация контента, 152-ФЗ трансграничный гейт, антифрод чарджбэков) реализованы+протестированы, но НЕ импортированы в живой `server.ts` — живут в мёртвом legacy `index.ts`.
6. **`/admin/worker` мониторит 4 несуществующие очереди**, не видит 2 реальные (`close-contests-cron`, `finalize-earnings-cron`) → вечный ложный «ok».
7. **`orgs/[id]` transferOwner осиротит оргу** (owner_id→NULL при опечатке email, нет проверки существования).
8. **Годовой тариф = месячные кредиты** (платишь ×10-12, получаешь ×1) — независимый от R1 баг.
9. **Фейк `AggregateRating` утекает в Google** JSON-LD (`ratingValue 4.4, reviewCount 395` при 0 отзывов) — нарушение structured-data, не косметика.
10. **Playground: копирайт «демо/mock/заготовлено» — ЛОЖЬ**; код реально стримит боевую модель (или глотает биллинг → бесплатный ответ). Round-1 вывод «механика mock» ОШИБОЧЕН. Худшее из миров: платим/отдаём бесплатно И называем фейком.
