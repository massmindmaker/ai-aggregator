# A3 — deploy-fee / hire-fee: ресёрч рынка и решение

> Статус: **ОТЛОЖЕНО** (решение основателя 2026-07-10: «отложим, но проведи ресёрч»). Данные: `scout14-a3-pricing-research.md` (17 площадок, снято 2026-07-09/10). Прод-объёмы: `scout12-prod-volumes.md`.

## Почему отложено — настоящая причина
Не в отсутствии цифры. **Deploy-fee не к чему привязать:** managed-Hermes не построен (канон §5, инфра-блок). Пока агент исполняется на нашем общем BullMQ-воркере, отдельный «деплой» не создаёт выделенного ресурса — брать за него нечего. Fee появляется вместе с резидентным подом, не раньше.
Прод пуст (0 ранов агентов за всю историю, 0 подтверждённых топ-апов, 2 TG-юзера) → любая цифра сейчас — гадание без спроса.

## Факты рынка (2026-07)
**Себестоимость резидентного мелкого процесса 24/7 (300-600MB — профиль Hermes chat-only):** Fly.io ~$2/мес (мин.) · Render $7/мес/сервис · Railway ~$30/мес (1vCPU+1GB) · Vercel Active-CPU $0.128/час активного времени (простой почти бесплатен).
**Подписки агент-хостингов:** Dify $0/$59/$159 · Coze ~$9-10 · FlowiseAI $35/$65 · CrewAI $0/$25/Enterprise · n8n $24/$60/$800. LangGraph Plus: $0.001/node + $0.0036/мин standby + $39/seat.
**Rev-share софт-маркетплейсов:** GitHub Marketplace 5% · JetBrains 15% (гарантия автору ≥75%) · Shopify 0% до $1M lifetime → 15% (+2.9% платёжка) · VS Code заявлено 5% (paid-extensions де-факто не работают) · Figma не раскрывает.
**Creator payout у агент-платформ:** реальный rev-share только у Poe (до $10k/1000 сообщений; % подписки не публикуется). OpenAI GPT Store — payout заявлен, формула непубличная. Character.AI — выплат авторам нет.
**Telegram Stars:** платформа берёт 0%, но эффективно ~32% на мобильных покупках (Apple/Google 30%) и ~3-4% на десктопе (Fragment-спред).
**Крипто:** Virtuals — разовый 100 $VIRTUAL launch-fee + 1% trading tax на оборот токена агента. Olas — стейкинг (fee не публичен). Fetch.ai Agentverse — бесплатно (Beta).

## Решения-кандидаты (к утверждению основателем — НЕ строить до отмашки)
- **D-A3-1 — hire-fee = 0.** Не вводить. Author-rent 0% — заявленный магнит для авторов (решение №7); брать с найма отдельно = сломать обещание. Наём монетизируется наценкой на модель (после фикса #5 дебет корректно ложится на нанимателя).
- **D-A3-2 — deploy-fee появляется ТОЛЬКО вместе с managed-Hermes.** Модель: «managed-агент» ≈ **$5/мес за резидентный под** (себестоимость $2-5, ориентир рынка — Render $7). Наш общий worker остаётся бесплатным путём. До существования пода — fee не вводить.
- **D-A3-3 — Telegram Stars не использовать** (подтверждено: ~32% эффективных на мобиле). Крипто-кредиты остаются.
- **D-A3-4 — Virtuals-модель (launch-fee + % с оборота токена) не копировать** — спекуляция, запрещена решением №4.
- **D-A3-5 — если когда-нибудь появится платный шаблон** (не аренда), калибровать долю площадки в коридоре 5-15% (GitHub 5 / JetBrains 15). Author-rent при этом остаётся 0%.

## Что разблокирует A3
Phase-0 спайк managed-Hermes (канон §5, R4): отдельный VPS 4-8GB, измерить реальный RAM/мультиплексинг пода. Без этих чисел цена «managed-агента» — оценка, а не расчёт.
