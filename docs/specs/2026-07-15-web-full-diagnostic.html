1. Вердикт: demo-ware по доказательствам

Витрина живая (не Потёмкин): страницы 200, регистрация (email+Яндекс, VK за флагом), B2B-ключи, каталог, подача модели, регистрация на конкурс — реально пишут/читают БД (проверено кодом + прод-curl + браузер-QA). Инфраструктура крепкая: списание атомарно, markup-флор на проде стоит (0 моделей в убыток), white-label в гейтвее закрыт, API-ключи полностью работают.

Но два сквозных потока мертвы: (1) попробовать модель — чат-апстрим 403 IP-бан РФ; (2) потратить деньги — три несвязанных леджера, оплата не даёт баланса гейтвею. Ни один живой юзер не может ни оплатить сквозь, ни получить ответ модели.

2. 🔴 Ядро финмодели — 3 P0 = одна проблема

Три несвязанных леджера, моста нет (подтверждено комментарием в самом коде billing/summary/route.ts:16-22):
  • топап → пишет users.balance
  • покупка тарифа → пишет subscriptions.credits_limit
  • гейтвей списывает → только organizations.payg_credits
Итог: оплатил Pro → баланс шлюза 0 → первый вызов → 402 INSUFFICIENT_FUNDS. Замаскировано тем, что Tinkoff-env не задан и чат 403 — до 402 никто не доходит. При включении оплаты дефект гарантирован.

Плюс «кредиты подписки» — чистая декорация: creditsUsed не инкрементится нигде. Лимит 1200/3200/10000 не считается и не блокирует. Учёта токенов по подписке — нет.
