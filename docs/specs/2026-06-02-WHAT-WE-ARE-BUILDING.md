## 1. Что это — в одном абзаце

**TMA — это хостинг и маркетплейс ИИ-агентов внутри Telegram, построенный вокруг агент-движка Hermes.** Пользователь либо берёт готовый **шаблон** агента и кланирует себе, либо собирает своего; агент работает на **нашей инфраструктуре** (экземпляр Hermes) — или пользователь подключает **своего** Hermes. Модели можно брать у нас (за рубли, с нашей наценкой) или **своим ключом** (бесплатно). Агент умеет навыки, инструменты, MCP-серверы, базы знаний и расписания. Оплата — простым **рублёвым балансом**.

## 2. Для кого и какую боль решаем

Hermes — мощный открытый агент, но он ставится **локально и для одного человека** (нужно поднять сервер, править 150 полей конфига). Все существующие UI для него — одиночные пульты «у себя на машине».

**Наша лужайка (которой нет ни у кого):** хостинг (ничего не ставить, работает в телефоне) + **маркетплейс готовых шаблонов** (тапнул — склонировал) + **оплата в ₽ с нашей наценкой** + выбор провайдера + **маркет инструментов**.

> Важно: **чат-доставку мы НЕ строим** — Hermes сам подключается к ~22 мессенджерам (Telegram, Discord, Slack, WhatsApp…), он уже Telegram-бот из коробки. Наша ценность — слой хостинга, маркетплейса и оплаты поверх него.

## 3. Ядро продукта — главный цикл

```
  ШАБЛОНЫ            ВЫБОР/СБОРКА          ЗАПУСК АГЕНТА                 ОПЛАТА
 (витрина,          склонировал        Hermes на нашей инфре  ──▶  списание с ₽-баланса
  у каждого    ──▶  или собрал    ──▶  ИЛИ твой свой Hermes         за прогон + за тузы
  видны модель      своего агента      │                            (свой ключ → 0)
  и цена)                              провайдер: наш (комиссия)
                                       / свой ключ (бесплатно)
```

### Три способа завести агента

1. **Подключить своего Hermes** — у тебя уже есть запущенный Hermes (на своём сервере). Подключаешь его к TMA по OpenAI-совместимому адресу, и **TMA становится оболочкой/пультом** над ним: прямо из TMA цепляешь к своему Hermes **скиллы** и **наших провайдеров** (модели). Рантайм — твой; мы даём удобный фронт + провайдеров + маркет инструментов.
2. **Создать по шаблону** — берёшь готовый публичный шаблон (видно модель + цену прогона), клонируешь себе, правишь под себя.
3. **Создать с нуля** — собираешь спек агента сам (персона + модели + скиллы + инструменты + MCP + базы знаний + расписания).

В случаях 2–3 агент работает как экземпляр Hermes **на нашей инфре** (или, по выбору, на своём). Провайдер моделей в любом случае: наш (комиссия) или свой ключ (бесплатно).

## 4. Из чего состоит агент («спек») — подтверждено по Hermes v0.15.2

Агент — это не один промпт и не одна модель, а **композиция**:

- **Персона** — характер и инструкции (файл `SOUL.md` + пресеты).
- **Модели — несколько под задачи** (подтверждено): отдельно чат-«мозг», генерация картинок, голос-из (TTS), голос-в (STT), зрение. Каждая — у любого провайдера.
- **Навыки (skills)** — переиспользуемые процедуры + мини-скрипты; есть хаб для установки.
- **Инструменты/плагины** — что включено (веб, терминал, файлы, картинки…).
- **MCP-серверы** — внешние серверы инструментов (по адресу/команде).
- **База знаний / память** — приватные заметки агента, профиль, история. *(приватно — см. §6)*
- **Расписания (cron)** — повторяющиеся задачи («каждое утро — сводка»).

## 5. Шаблоны: приватный / публичный

Агента можно создать **приватно** или **публично**. «Публично» **НЕ** раскрывает знания/данные — отдаются только **настройки (спек)**, чтобы другой человек мог склонировать такую же сборку.

| Отдаётся в публичном шаблоне ✅ | Остаётся приватным 🔒 |
|---|---|
| Персона (`SOUL.md`), пресеты | API-ключи (отдельный `.env`) |
| Выбор моделей — **только названия, без ключей** | Заметки/память агента |
| Навыки (процедуры + скрипты — проверять на секреты) | Профиль пользователя |
| Какие инструменты включены | История переписки (и биллинг внутри неё) |
| Определения MCP — **без токенов** | Подключённая база знаний |
| Расписания — **без приватных chat-id/путей** | Живые токены подключённых сервисов |

У шаблона на карточке сразу видно: **какая модель + примерная цена прогона**.

> ⚠️ У Hermes **нет** официальной команды «экспортировать агента целиком» — наша упаковка шаблона (персона+настройки+навыки+расписания) это **наш формат**, который мы определяем сами.

## 6. Оплата

Две раздельные «кассы» (сегодня НЕ связаны): **кошелёк пользователя в TMA** (рублёвый баланс — это про агентов) и **балансы организаций в шлюзе** (B2B-слой для API, к Telegram не подключён — не путать).

- **Пополнение баланса (₽ через TON Connect)** — ✅ работает. От 100 до 50 000 ₽, хранится в рублях, атомарно, защита от двойного начисления. Кредит делается **серверной проверкой TonCenter** (не на доверии клиенту). *(слабое место: опрос подтверждения инициирует само приложение — если юзер закрыл его до подтверждения, никто не дозапросит позже; нет автономного крона-дозорного — 🔨 R1-6.)*
- **Списание за прогон** — ✅ работает. Перед стартом 3 проверки (мес. бюджет, дневной бюджет, баланс ≥ 1₽); в конце одной транзакцией: выполнено + дневной расход + списание. Сбой откатывает всё.
- **Оплата за инструменты (тузы)** — ✅ механика есть (стоимость инструмента прибавляется к прогону; пока платная только генерация картинок ~6.5₽). 🔨 отдельный брокер платных внешних инструментов/MCP — потом.
- **x402** — ⏸ способ, которым **агент платит наружу** чужому платному сервису (не пополнение, не внутреннее списание). В коде пока нет, R&D, зарубежное юрлицо.
- **Свой кошелёк пользователя** — ⏸ отложено (нужна единая денежная единица + проверка подписи кошелька; крипта — не на РФ-юрлице).

**Правило комиссии — ✅ соблюдается в коде:** свой ключ (OpenRouter, Gonka, любой) → списания 0; наша модель → списываем. Наценку/«белый лейбл» накладывает путь через шлюз `:4000` (ключ шлюза уже прописан в этой сессии; осталось завести дефолтную модель в реестр шлюза).

**Граница двух юрлиц:** РФ-юрлицо = всё рублёвое (пополнения, чеки, баланс, прогоны). Зарубежное = всё крипто-агентное (x402, прямые крипто-траты) — до оформления структуры не запускаем.

## 9. Что НЕ делаем / убрали

## 10. Инфраструктура (❓ открытое решение)

Каждый агент-Hermes = **отдельный процесс** (~300 МБ в покое, до 1–2 ГБ с браузером). Режима «один на всех» у Hermes пока нет. **Текущий VPS 2 ГБ это как продукт НЕ тянет** (влезает 0–2 агента). ⚠️ **Безопасность:** профили Hermes не изолированы — чужой агент на нашей машине может прочитать наш `.env` с ключами; нужна песочница.

Варианты (❓ решить):
- **Песочница по требованию (Daytona/Modal)** — агент включается когда нужен, спит в простое, ~$0.30/агент/мес, масштабируется, безопаснее; но доллары → зарубежное юрлицо.
- **Большой VPS 8–16 ГБ + Docker-песочница** — ~10–30 агентов, остаётся на РФ-юрлице, проще для беты; потолок и платим за простой.
