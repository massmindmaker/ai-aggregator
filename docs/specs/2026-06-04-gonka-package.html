01 · The pitch

A marketplace of personified AI agents that live inside Telegram.

RU-market agent marketplace + an OpenAI-compatible API gateway. Three pillars the grant rides on: author-rent monetization, a credit-hub billing rail, and Gonka as a selectable inference provider.

◐Agent marketplace

Discover / run / clone-from-template / build your own. An agent = a composable SPEC (persona + models + skills + tools + MCP), not a prompt. Templates are published, not sold — they share the setup, never the keys or data.

₵Author-rent + credit-hub

Authors publish free or set a rent price; the user pays model usage (markup) + the author's exact sum — AIAG takes 0% on author rent. One canonical credit unit (1 cr = 1 US cent) on an append-only ledger. Multi-crypto top-up (TON live on testnet).

why Gonka

⚙Each agent picks a provider

Every model in a spec carries a provider. AIAG-supplied → markup; own key / BYO-wallet = 0 commission. Gonka is one selectable provider — we route real RU demand to it and earn on the grant, not a per-call Gonka tax.

04 · UX notes

Honest, mobile-first, credit-native.

Telegram-native, single-column, thumb-reachable. UI = reality: every feature carries an honest live / скоро / R&D label and never dead-ends a paid flow into an unbuilt screen.

₵One credit unit

"Credits / кр" everywhere (1 cr = 1 US cent). Never contracts, gas, or raw ₽. All numerics in JetBrains Mono. Top-up via TON Connect + HOT Wallet — no Telegram Stars.

▤Run-trace + budget-card

The "what did my agent do" surface: a vertical step timeline + collapsible tool-call cards (mono tool name, args/result, duration + token + cost badge, status pill). The budget-card shows daily + per-call cap + allowlist — the delegated-wallet UI.

◈Character cards

Agents are personified characters (per-character OKLCH hue, portrait, name + role), not emoji rows. The user's own /agents list now speaks the same collectible-card language as the catalog — the founder's top design gap, closed.

  • One amber primary CTA per screen — everything else is secondary ghost.
  • Status pills are icon + word, never color alone — accessibility + the honesty rule.
  • Provider-picker rows make the rule legible — AIAG (+наценка) / OpenRouter / BYOK / Gonka / Custom · «свой = 0 комиссии».
  • Hairline elevation, amber glow on hover — no generic SaaS card shadows, no AI-slop gradients.
