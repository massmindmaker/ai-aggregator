## Граница продукта

Маркетплейс моделей и исполняемых алгоритмов, включая опубликованные API решений агентов/RAG. Владеет реестром коммерческих версий, вызовами, ценами, денежным журналом и авторскими начислениями. Долгоживущие агентские сессии принадлежат Agents Market, конкурсные рейтинги — Arena.

## Где вести работу

Кандидат: `/home/bob/Projects/aiag-web/repo`; модули `apps/web`, `packages/api-gateway`, `packages/database`, `apps/worker`. При E0 сопоставить с `/home/bob/Projects/aggregator/core`. Текущая архивная папка — место подготовки плана, не подтверждённый источник релиза.

## Исходное состояние

Подтверждены код каталога/gateway/админки, недавние transactional payment settlement и CloudPayments. Не доказаны единый end-to-end кошелёк, готовность авторской модели к вызову и выплата дохода. Асинхронные worker sinks частично заглушены. Исторический балл 65.5/108 не переносится в новый scorecard.

## Очередь реализации

| Пакет | Приоритет / зависимость | Что делать и где | Критерий выхода |
|---|---|---|---|
| AG-W0 | P0, E0 | Сверить payment/gateway миграции и сохранённые изменения двух repo; определить денежные единицы и действующий release | Есть выбранный источник и тестовый стенд с воспроизводимым запуском |
| AG-W1 | P0, W0 | `payments/settle`, topup/subscriptions, gateway billing: проследить payment → account/org → расход; убрать разрыв учёта и float на критичных суммах | Один платёж даёт доступный лимит; два одновременных webhook начисляют один раз; списание объяснимо |
| AG-W2 | P0, W1 | Usage persistence, stream usage, reservation, cancel/refund/reconcile; обрыв SSE, timeout, provider success + local crash | Возврат соответствует журналу; нет двойных начислений; неуспех не теряется |
| AG-W3 | P0, W2 | Авторский endpoint/manifest → moderation → adapter/model version → priced invocation → earnings | Независимый тестовый автор продаёт один реальный вызов; видно корректное начисление |
| AG-W4 | P1, W3 | Публичный каталог capabilities/price revisions, quotas; worker polling/sinks и ошибки; feature gates модальностей | Все включённые в v1 типы дают сохранённый результат; неготовые не продаются |
| AG-W5 | P1, W3 | Payout state machine, locked claims, provider reconciliation, авторские отчёты и disputes | Повтор и сбой выплаты не меняют итог; ledger можно сверить с provider |
| AG-W6 | P1, W4/W5 | Кабинеты, a11y, честная витрина, API документация, мониторинг, backup/recovery | AG-01…AG-12 закрыты по I/T/O; integration suite пройден |

Авторский путь — обязательный критерий marketplace. Каталог чужих API без продажи решения независимого автора не достигает 108/108. Начинать можно с одного типа HTTPS text endpoint; embeddings/image/audio/video включать по мере закрытия полного денежного и async-цикла. Состав модальностей v1 фиксируется в E0 и после этого не сокращается ради балла.

Бесплатные гранты, процент комиссии и FX-правила не выводить из старых констант. Сначала восстановить действующую продуктовую политику, затем хранить её в одном версионированном источнике. Финансовую операцию нельзя считать завершённой только по redirect success от платёжной формы.

**Контрольная демонстрация:** покупатель пополняет тестовый баланс, получает ключ, вызывает модель автора в stream и non-stream, видит usage; автор видит начисление; повтор webhook ничего не меняет; refund корректно отражён с обеих сторон. Боевые деньги только отдельным согласованным шагом.

Ответственный за реализацию — владелец этого продукта; интерфейсы проверяет также владелец потребителя. Блокирующие дефекты денег/изоляции/потери данных запрещают выпуск при любом балле. Финал — 108 PASS на согласованном составе v1 плюс обязательные сквозные проверки.
