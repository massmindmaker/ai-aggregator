# Agents Market TMA: самостоятельное Telegram-приложение

Уточнение основателя от 06.09.2026. Обязательная часть v1 наряду с полноценным Web.

Исходник: `/home/bob/Projects/aggregator/core/apps/tg-miniapp`. Целевая папка после сверки — `agents-market/apps/tma`. Существующий код и рабочие Telegram-потоки сохраняются при выделении; это не повод переписывать приложение с нуля.

## Продуктовый результат

Быстрый путь внутри Telegram: открыть → выбрать/нанять агента → задать задачу → получить результат и понять стоимость. Создание и настройка доступны в компактном виде; сложные настройки можно продолжить в полноценном Web по безопасной ссылке. Критичные действия, обещанные в TMA, не должны заканчиваться неработающей кнопкой или обязательной установкой ещё одного приложения.

Один backend с Web; отдельные auth adapter, навигация, Telegram UI integration и release. Telegram user id никогда не принимается как доверенный просто из query. Связь web account не выводится из username. Бот-уведомления не раскрывают приватные результаты без настроенного согласия пользователя.

## Обязательный сценарий выпуска

Открыть TMA из бота, войти через проверенный initData, нанять агента и запустить задачу. Закрыть приложение во время run, открыть снова и увидеть ровно один результат и расход. Проверить недостаток средств, потерю сети, отказ runtime, истечение сессии и возврат из оплаты. Связать подтверждённый web account и открыть историю в Web; отключить связь без доступа чужого аккаунта к оставшимся сессиям.

Браузерный iframe smoke не заменяет проверку внутри Telegram. Вся матрица клиентских сценариев должна иметь факт проверки на реальном поддерживаемом клиенте. До финального выпуска выбрать и записать точные версии устройств/клиентов.

Баллы учитываются в [общем scorecard Agents Market](./agents-market-scorecard.csv). Для интерфейсных пунктов нужны доказательства и Web, и TMA. Общие API-тесты не заменяют Telegram auth, keyboard, BackButton и lifecycle проверки.
