# Agents Market Web: самостоятельное приложение

Уточнение основателя от 06.09.2026. Обязательная часть v1, самостоятельная от TMA веб-версия.

Целевая папка: `agents-market/apps/web` внутри будущего рабочего контура Agents Market. Перед реализацией проинвентаризировать существующий `/agentmarket` в `core/apps/web`: использовать пригодные компоненты и маршруты, не считать спрятанную страницу полноценной веб-версией. На текущем шаге папки и код не переносились.

## Продуктовый результат

Человек может пользоваться агентами без Telegram: зарегистрироваться, найти/нанять/создать агента, подключить свой runtime, выполнить задачу, управлять расписаниями и расходами. Автор получает полноценный кабинет публикаций, версий, дохода и поддержки. Интерфейс адаптируется к mobile web; desktop даёт больше места настройкам, результатам и сравнению версий.

Общий backend с TMA: users/linked identities, templates/instances, hires, runs, budgets, payments и permissions. Web имеет собственную сессию; Telegram initData не является условием работы. Существующий пользователь может связать аккаунты через подтверждение обоих. После связывания баланс и агентские данные едины в рамках Agents Market, но не объединяются с кошельками других продуктов автоматически.

## Обязательный сценарий выпуска

Новый web-пользователь без Telegram нанимает агента, задаёт бюджет, получает результат, видит расход. Автор публикует новую версию и получает начисление. Пользователь связывает свой Telegram и открывает TMA: видит те же доступные агенты и историю. Повторная доставка событий не меняет баланс. Несвязанный Telegram-пользователь ничего из этого не видит.

Проверить Chrome/Firefox и mobile browser по согласованной browser matrix; основные действия доступны клавиатурой; refresh/back не создают повторных оплат. Поля с секретами очищаются при выходе; service keys отсутствуют в клиентском bundle.

Баллы учитываются в [общем scorecard Agents Market](./agents-market-scorecard.csv). Для клиентских требований в evidence обязательно указать `WEB: ...; TMA: ...`; отсутствие одного канала оставляет проверку незакрытой. Отдельная задача AM-WEB-10 не закрывает AM-TMA-10.
