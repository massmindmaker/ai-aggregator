## Цикл, ради которого всё и делается

```
Arena: пользователь разрабатывает модель → конкурс → оценка → evidence
   ↓ POST /v1/publication-drafts (с согласия автора)
Aggregator: модерация → продаваемая версия → автор получает начисление
   ↓ GET /v1/catalog + inference API (покупает своим кошельком)
Agents Market: агент сам выбирает и покупает модель в цикле работы
```

Ключ цикла — `ArtifactManifest v1`: версия неизменяема, идентифицируется
`(source_product, artifact_id, version_id)` + `content_digest`. Ссылка на плавающий
`latest` запрещена. Рейтинг не переносится на новую версию молча.
