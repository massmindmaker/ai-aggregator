# AIAG — пайплайн разработки

> Этот скилл = «как мы строим в AIAG». Объединяет Superpowers + нашу структуру памяти + наш порядок работы. Сверяйся с ним в начале любой нетривиальной задачи.

## 0. ПАМЯТЬ (всегда первым — иначе дрейф/галлюцинации)
- **Канон `docs/canon/AIAG-CANON.md` = единственный источник истины.** ОБЯЗАТЕЛЬНО сверься с ним перед работой. При конфликте recalled-памяти с каноном — побеждает канон.
- Роли систем: канон=продукт/модель · Serena=код/антипаттерны/баги · LightRAG=ресёрч · memgraph=граф сущностей · graphify=код-AST · auto-memory=факт-указатели · DESIGN.md=токены.
- **После изменений:** обновить канон → синхрон memgraph-узел + auto-memory-указатель; после кода → `graphify update`; новый ресёрч → LightRAG `upload_document` (НЕ insert_text). Старьё не удалять — DEPRECATED→канон.

## ПАЙПЛАЙН ФИЧИ (порядок)
1. **Брейншторм** (`superpowers:brainstorming`) — идея → спека (`docs/superpowers/specs/`). Hard-gate: дизайн утверждён до кода.
2. **Wireframe** (`wireframe-kit`) — ч/б каркас всех экранов/модалок (структура важнее цвета). Борды в `docs/wireframes/`.
3. **Hi-fi** — брендовый dark/amber слой поверх каркаса по `DESIGN.md` (когерентно с `design-board.html`, не «второй апп»).
4. **Исследования** (параллельные субагенты): (а) технологии/Hermes — какой API/подход построить; (б) продукт/UX — референс-паттерны у лучших; (в) полнота vs канон. Источники — в LightRAG.
5. **Критика 108** — оценка по осям (бизнес-логика · workflow · UX · дизайн · полнота-vs-Hermes). Честные статусы live/скоро/R&D/ПРОЕКТ.
6. **План** (`superpowers:writing-plans`) → **исполнение** (`superpowers:subagent-driven-development`, fresh-субагент на задачу + ревью).
7. **Деплой** (skill `aiag-deploy`): `gh workflow run deploy-production.yml --ref BRANCH -f ref=BRANCH -f apps=tma`; авто-деплой; прод `app.ai-aggregator.ru/tg`; проверить health.

## ПРАВИЛА ИСПОЛНЕНИЯ (выработаны сессиями)
- **Максимум субагентов / Workflow** для веера (разные файлы/системы → параллельно; одинаковые → последовательно, иначе гонки). Агенты в фан-ауте НЕ коммитят — коммитит координатор одним проходом.
- **Money-path неприкосновенен** (`apps/agent-worker` settleRun, биллинг): любые правки — только additive, проверять diff на «не задет ли биллинг».
- **Гейт typecheck** перед коммитом (`bunx tsc --noEmit` пуст), миграции на прод ДО деплоя кода (иначе SELECT новой колонки → 500).
- **UI = reality:** не показывать непостроенное как рабочее; статус-пилюли честные.
- **Антипаттерны** (Serena `aiag_antipatterns`): цена×100 (юзать `@/lib/credits`), namespaced model-слаги, квалифицировать колонки после JOIN, `sudo -n pm2 jlist`, `bun install --offline` (VPN-прокси), не коммитить без гейта.

## РАСШИРЕНИЕ
Новые домены (маркетинг/юр/финансы) → канон §15+ + категория в Serena/LightRAG. Структура НЕ переделывается — дорастает.
