breakdown

### [nesquena / hermes-webui](https://hermesatlas.com/projects/nesquena/hermes-webui)

This lightweight Python and vanilla JavaScript interface provides full feature parity with the Hermes CLI in a mobile-responsive web format. It features a three-panel layout that allows users to browse workspace files and view inline previews alongside their active agent sessions.

### [EKKOLearnAI / hermes-web-ui](https://hermesatlas.com/projects/EKKOLearnAI/hermes-web-ui)

A comprehensive dashboard focused on multi-platform connectivity, offering unified configuration for eight channels including Telegram, Discord, and WhatsApp. It includes real-time session persistence, tool call expansion, and detailed analytics for tracking token usage and costs across different models.

### [outsourc-e / hermes-workspace](https://hermesatlas.com/projects/outsourc-e/hermes-workspace)

Designed for zero-fork compatibility with vanilla Hermes installations, this workspace integrates a memory browser, terminal, and skills manager into a single interface. Its standout Swarm Mode enables role-based dispatching, allowing users to coordinate multiple persistent agents simultaneously.

### [fathah / hermes-desktop](https://hermesatlas.com/projects/fathah/hermes-desktop)

This desktop companion simplifies the initial setup of Hermes Agent with a guided installer for local dependencies and environment configuration. It provides a unified GUI to manage 16 messaging gateways and 14 toolsets, complemented by full-text search for session history.

### [dodo-reach / hermes-desktop](https://hermesatlas.com/projects/dodo-reach/hermes-desktop)

A native macOS workspace that uses direct SSH connections to ensure the remote host remains the single source of truth for all agent data. The application organizes the Hermes experience through specialized views for Kanban boards, cron jobs, and profile-aware terminal sessions.

### [xaspx / hermes-control-interface](https://hermesatlas.com/projects/xaspx/hermes-control-interface)

This self-hosted gateway acts as a command center for starting, stopping, and configuring individual agent profiles. It provides deep system visibility through an integrated xterm.js terminal, real-time system metrics, and granular token analytics for cost management.

### [clawvader-tech / hermes-telegram-miniapp](https://hermesatlas.com/projects/clawvader-tech/hermes-telegram-miniapp)

This mobile-first React dashboard is built specifically as a Telegram Mini App, offering a 10-page UI for managing agents on the go. It supports background spawning for up to five concurrent instances and includes visual gauges for monitoring CPU, memory, and disk usage.

### [pyrate-llama / hermes-ui](https://hermesatlas.com/projects/pyrate-llama/hermes-ui)

A glassmorphic React 18 application that pairs a lightweight Python proxy with a modern aesthetic for self-hosted AI management. The interface supports real-time log streaming and a live workspace file browser, making it easy to preview files and manage MCP tools.

### [aivrar / portable-hermes-agent](https://hermesatlas.com/projects/aivrar/portable-hermes-agent)

A zero-install Windows GUI that operates without admin rights or Docker, focusing on local workflows like TTS, music generation, and ComfyUI. It features a dynamic tool maker for creating custom API wrappers and comes pre-loaded with over 100 specialized tools.

### [sanchomuzax / hermes-webui](https://hermesatlas.com/projects/sanchomuzax/hermes-webui)

A monitoring-focused dashboard that provides a real-time activity feed and cost tracking for active Hermes sessions. It utilizes FTS5 search for deep inspection of conversation histories and allows users to manage scheduled cron jobs and read-only configurations.

### [Euraika-Labs / pan-ui](https://hermesatlas.com/projects/Euraika-Labs/pan-ui)

This chat-first workspace emphasizes extensibility through an integrated marketplace for discovering and installing new skills and MCP servers. It features SSE streaming for real-time responses and profile-scoped management of global memory and agent runtimes.
