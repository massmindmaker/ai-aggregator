# AIAG session 2026-07-15/16 — web-диагностика + разворот финмодели веба

## Финмодель веб-агрегатора — РЕШЕНИЕ ОСНОВАТЕЛЯ 2026-07-15 (см. канон §6-доп, `MEMORY.md` project_web_finmodel_decision_2026_07_15)
- Разворот: НЕ рубли за использование — **КРЕДИТЫ** (модель Higgsfield: тариф даёт N кредитов, докупаются PAYG).
- **1 кредит = 1 цент США** — тот же юнит, что уже в TMA (`apps/tg-miniapp/src/lib/ton-rate.ts`, USD-peg, `tg_user_balances.balance_credits` BIGINT). Кредит совпадает между web и TMA — прямое требование основателя (единая экономика продукта).
- Markup поднимается **1.20× → 1.8×** (прод сейчас занижен).
- Тарифы: Free 0₽=200 кр (whitelist ТОЛЬКО дешёвых моделей: gpt-4o-mini/DeepSeek/Haiku) · **Lite 290₽=300 кр (новый тариф**, вход вровень с конкурентами ChadGPT/BotHub) · Basic 990₽=1100 кр (маржа 43%) · Starter 2490₽=2900 кр (40%) · Pro 6990₽=8400 кр (39%).
- Кредиты подписки **сгорают** в конце периода; докупленные (payg) — НЕ сгорают. Годовой тариф капает кредиты **помесячно** (не разово на год).
- Формула стоимости: `credit_cost = max(1, ceil(upstream_usd × markup × batch × caching × 100))` — переносится 1:1 из TMA (`agent-runner.ts:433`).
- Статус: РЕШЕНО основателем, реализация НЕ построена — нужен мост оплата→org-бакеты кредитов, реальный учёт расхода, лимиты в ЛК.
- Юр-риск (известный, отложен основателем «в последний момент»): оферта/условия/политика конфиденциальности на сайте — черновики с фейковым ОГРНИП `0000000000`, а сайт уже принимает боевые рубли через Tinkoff.
- ⚠️ Канон (`docs/canon/AIAG-CANON.md` §2 таблица, "Валюта: РУБЛИ (₽)") пока описывает web как рублёвый — это верно для приёма платежа (Tinkoff остаётся ₽-эквайрингом), но ВНУТРЕННИЙ юнит расхода меняется на кредиты. Помечено в каноне `DEPRECATED → канон §финмодель-web` там, где текст подразумевал прямой рублёвый расход = кредитный юнит.

## Security-review (встроенный скилл) — 1 HIGH, найден и не смёржен на момент записи
- `apps/agent-worker/src/agent-runner.ts:943` — `runSubAgent(agent.tg_user_id, a)` передаёт ВЛАДЕЛЬЦА агента как принципала звонка. На найм-ране должен рулить НАНИМАТЕЛЬ (`run.tg_user_id`). Guard на `:511` авторизует делегирование против флота ВЛАДЕЛЬЦА → наниматель может делегировать в приватные агенты владельца и сжечь его BYOK-ключ (cost=0 для нанимателя). Тот же класс бага, что уже починенный issue #12 (`notifyCompleted`) — пропущенный call-site того же паттерна. Фикс в работе, не задеплоен на момент записи.
- Латентные, не блокирующие: payout TOCTOU (сейчас неэксплуатируем — `sendUsdtTransfer` бросает исключение; станет реальным двойным выводом когда выплаты включат); SSRF-allowlist переширок на BYOK-URL.
- Чисто: SQLi нет (tagged templates везде), RCE нет, XSS нет, initData HMAC + JWT-пиннинг корректны, 28 TMA-роутов фильтруют владение, Tinkoff-вебхук идемпотентен, `settleRun` атомарен, `safeFetch` точный allowlist.
