# AIAG — Реестр багов (симптом → причина → фикс → коммит)

> SoT-канон: `docs/canon/AIAG-CANON.md`. Паттерны-обобщения — в `mem:aiag_antipatterns`.

## HTTP 500 при открытии агента
- **Симптом:** открытие страницы агента → HTTP 500, в логах Postgres `42702 column reference "updated_at" is ambiguous`.
- **Причина:** после добавления MCP-JOIN в запрос колонка `updated_at` стала неоднозначной (присутствует в нескольких таблицах JOIN).
- **Фикс:** квалифицировать колонку таблицей — `agents.updated_at` (и аналогичные неоднозначные поля).
- **Коммит:** `fa9ea23`.

## cloneable / trait — SELECT до миграции
- **Симптом:** запросы с новыми колонками (`cloneable`, trait-поля) падают на проде — колонки нет.
- **Причина:** код задеплоен раньше, чем применён ALTER (прод-миграции ручные, без трекинга).
- **Фикс:** применять `ALTER` на прод-БД ДО деплоя кода, который SELECT'ит новые колонки. Порядок: миграция → деплой.

## Маркет пустой
- **Симптом:** экран маркета/каталога шаблонов пуст (потёмкинская витрина).
- **Причина:** таблица `agent_templates` = 0 строк на проде.
- **Фикс:** засеять `agent_templates` реальными шаблонами (либо честный empty-state). Слаги моделей в шаблонах сверять с прод `models` (иначе margin-leak — см. `mem:aiag_antipatterns`).

## mintFeeTon вне scope
- **Симптом:** компонент минта/transfer не видит `mintFeeTon` (undefined) — комиссия минта недоступна в дочернем компоненте.
- **Причина:** значение не проброшено через props в дочерний компонент.
- **Фикс:** пробросить проп `mintFeeTon` вниз по дереву до места использования.
