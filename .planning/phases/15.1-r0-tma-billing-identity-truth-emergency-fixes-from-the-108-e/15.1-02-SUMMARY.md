# Phase 15.1 Plan 02: TMA Auth Hardening Summary

**CVE-2025-29927 + alg-confusion blocked: Next.js bumped to 14.2.33, middleware HS256-pinned with fail-hard secret, auth/verify issues iss/aud/jti tokens, nginx strips the bypass header.**

## Accomplishments

- **R0-4 CVE closed:** Next.js 14.2.15 → 14.2.33 patches CVE-2025-29927 at the framework level; nginx snippet strips `x-middleware-subrequest` at the edge (belt-and-suspenders)
- **R0-4 alg-confusion blocked:** `jwtVerify` now requires `{ algorithms: ['HS256'], issuer: 'aiag-tma', audience: 'aiag-gateway' }` — `alg:none` and RS256 tokens are rejected with `JOSEAlgNotAllowed`
- **R0-5 fail-hard secret:** both `middleware.ts` and `auth/verify/route.ts` throw at module load if `TMA_JWT_SECRET` is unset or shorter than 32 chars — no silent dev fallback
- **R0-4 header strip:** middleware deletes inbound `x-tma-user-id` and `x-middleware-subrequest` before re-setting the verified value — defense-in-depth even if nginx directive is delayed
- **T-15.1-10 wiring:** issued JWTs now carry `jti`; `jwt-denylist.ts` provides `revoke` (functional, ioredis) and `isRevoked` (Edge-safe, stubs false for R0)

### nginx directive (HUMAN ACTION REQUIRED)

Merge the `/tg` location block from `infra/nginx/tg-miniapp.conf` into the live vhost at `/etc/nginx/sites-available/ai-aggregator.ru` (or the relevant include), then:

```bash
nginx -t && systemctl reload nginx
```

The critical directive is:
```nginx
proxy_set_header x-middleware-subrequest "";
proxy_set_header x-tma-user-id "";
```
