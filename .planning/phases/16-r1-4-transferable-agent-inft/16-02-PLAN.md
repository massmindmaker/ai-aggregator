import postgres from 'postgres';
export const runtime = 'nodejs';

Body shape: `{ transferable: boolean; price_credits?: number | null }`.
- `transferable: true` → mark transferable. `transferable: false` → un-mark (owner can withdraw the offer).
- `price_credits`: NULL/absent = gift-only (no sale price). A positive integer in (0, MAX] = sale price. Validate EXACTLY like publish (Number.isInteger && >0 && <=MAX, else 400 `invalid_price`).

Logic:
1. `const tgUserId = req.headers.get('x-tma-user-id');` — 401 `unauthorized` if missing.
2. `UUID_RE.test(params.id)` — 400 `invalid_id` if bad.
3. Parse JSON in try/catch → 400 `invalid_json` on failure.
4. Validate `transferable` is a boolean → 400 `invalid_body` otherwise.
5. Validate `price_credits` per the block above (only when transferable is true; when false, force priceCredits = null).
6. GUARDED UPDATE (the ownership guard is the security boundary — mirror loadAgent's WHERE):
```typescript
const upd = (await sql`
  UPDATE agents
  SET transferable = ${transferable},
      transfer_price_credits = ${priceCredits},
      updated_at = NOW()
  WHERE id = ${params.id}::uuid
    AND tg_user_id = ${tgUserId}::bigint
    AND status != 'deleted'
  RETURNING id::text, transferable, transfer_price_credits::text AS transfer_price_credits
`) as unknown as Array<{ id: string; transferable: boolean; transfer_price_credits: string | null }>;
if (upd.length === 0) return NextResponse.json({ error: 'not_found' }, { status: 404 });
return NextResponse.json({ agent: upd[0] }, { status: 200 });
```

IMPORTANT — this route does NOT mint, does NOT call Startonus, does NOT touch TON. CONTEXT.md decision #3: "Сделать передаваемым = бесплатный DB-флаг + цена (без газа)". The mint is lazy and happens in plan 03 at actual transfer. Do not import `generateInvoice` here. Do not write to `nft_address` here.
